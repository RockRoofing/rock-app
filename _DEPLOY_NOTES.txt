  EDIT  pages/operations/projects.js

WHAT CHANGED
Projects now have a third status alongside Live and Complete: ARCHIVED.
- The status dropdown on each project row now offers Live / Complete / Archived.
- The Status filter at the top now includes Archived (and still has Live / Complete / Draft / All).
- Archived projects show with a grey status pill.
- Add / Edit Project can set status to Archived too.

BEHAVIOUR
- Like Complete, Archived projects do NOT appear in the live Planning view (only Live and Draft
  do). Archived is simply a further "put away" state beyond Complete - useful for old jobs you
  want out of the Complete list but still retrievable.
- The upcoming Planning "completed projects" filter will let you pull Archived (and Complete)
  projects back into the planner on demand to check dates worked.

No data migration needed - existing projects keep their current status; you set Archived when
you want it.
