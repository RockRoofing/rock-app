WHY
---
Every project on this page comes from dashboard:cache:

    const dash = Array.isArray(dashCache) ? dashCache : []
    for (const p of dash) { ... }

If that key is empty the loop runs ZERO times, projects comes back empty, and the
page says "No applications found". It looks exactly like a code fault and is not
one.

The cache has a 4-hour life AND is dropped whenever a new cache marker ships -
and several of the packages I have given you added markers to dashboard.js
precisely to force a rebuild. Only the dashboard itself rebuilds it. So it went
cold, and this page had no way of saying so.

That is also why the earlier figures kept moving: 421,033 then 1,375,463 then 0
are three different states of that cache, not three different bugs.
