WHAT CHANGED
The Handover tab on an Operations project used to show only a short summary (about a dozen
fields). It now pulls through the FULL Internal Handover Minutes - every section and field from
the IHM template - by loading the same IHM template the Pre-Contract form uses and rendering
each field read-only:
  - all template sections and their fields (text, dates, rich text, etc.)
  - Site Contacts and Manufacturer Contacts
  - Roof Types
  - Risk Log
  - Procurement
  - Live Tasks
  - Handover documents (view / download)
Empty sections are hidden so it stays tidy. If the template can't be loaded for any reason, it
falls back to the old summary view.

STILL READ-ONLY (as requested) - no editing here. It reads the same data as the Pre-Contract
Internal Handover Minutes (single source of truth), so it always reflects the latest minutes.
Editing remains in Pre-Contract -> Internal Handover Minutes.
