DEPLOY NOTES - Force the H&S incident forms to always be present
===============================================================

ONE file, an EDIT - just replace it.
  pages/api/forms.js

WHY THEY WEREN'T APPEARING
  The H&S forms live in the code correctly, but they were never inserted into your live
  saved forms (seeding only ran when the form store was first created, before these
  forms existed). The manual "Add missing default forms" button relied on being clicked
  after the deploy landed, which is easy to miss.

FIX - AUTOMATIC, NO BUTTON NEEDED
  The forms API now ALWAYS ensures the three mandatory H&S incident/accident forms are
  present whenever the forms list loads:
     - ACCIDENT BOOK: H&S Incident Record
     - Near Miss Report Form
     - H&S Accident and Incident Report and Lessons Learnt
  If any are missing from your live set, they are added automatically. This is scoped
  to ONLY these H&S compliance forms, so it never touches or resurrects any other form
  you have created, edited or deleted.

AFTER DEPLOY
  Just open the Form Builder (or the Site App Forms list) once - the H&S forms will be
  there. They appear in the Site App under "H&S Incidents & Accidents" for both
  Operatives and Contracts Managers.

  IMPORTANT: this works together with the earlier section-rename file
  (HS_incidents_section.zip / pages/forms/index.js). If you haven't deployed that one
  yet, deploy it too so the Site App section shows and is labelled correctly.
