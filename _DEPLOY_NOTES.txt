WHAT CHANGES ON SCREEN
----------------------
The Pre-Contract nav goes from nine tabs to seven. "(CRM)" is dropped from the two that
remain, because there is nothing left to distinguish them from:

    Sales Dashboard  ->  /sales-crm
    Scorecards       ->  /scorecard-crm

The green comparison banners are gone from both - there is no longer anything to compare
against.

The portal tile and the CRM back button both now point at the new Sales Dashboard. I
checked for anything else linking to the old pages: nothing.

The URLs keep the -crm suffix. Renaming the files as well would have meant deleting and
recreating two large pages in the GitHub editor for a cosmetic gain, and would break any
bookmarks people have already made to /sales-crm.


ONE THING I FOUND WHILE DOING THIS - AND IT MATTERED
-----------------------------------------------------
The NEGOTIATING page was still running on Pipedrive.

/api/negotiating read getCachedDeals(), which is pipedrive:deals, kept current by the
sync cron. Deleting the two dashboards would not have broken it - but the day you switch
Pipedrive off it would have silently gone stale, showing a frozen list of deals that were
in Negotiating whenever the last sync ran. Exactly the failure we have spent the last
three packages removing everywhere else.

It now reads the CRM through the same adapter as everything else. The page subtitle said
"Live from Pipedrive"; it now says "Live from the CRM".

That was the last one. I searched every page: nothing in Pre-Contract reads
/api/deals, /api/value-changes, /api/sync or the Pipedrive cache any more.


WHAT IS STILL RUNNING THAT YOU MAY WANT TO STOP
-----------------------------------------------
Deliberately left alone - tell me and I will remove them:

  pages/api/sync.js            the Pipedrive pull
  pages/api/webhook.js         still records value changes to the old store
  pages/api/deals.js           now unused
  pages/api/value-changes/     now unused (the -crm one is separate and stays)
  the pipedrive-sync cron in vercel.json

None of it does any harm - it writes to keys nothing reads now. But it is dead weight, and
the crons cost you a run every hour for nothing. I have left them because removing the
webhook is irreversible without reconfiguring Pipedrive, and you may want a period where
the old data keeps updating in case you need to go back.

Say when, and it is a five minute package.
