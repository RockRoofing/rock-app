CHANGES
1. HIDDEN PROJECTS. Any project manually hidden on the Project Financials page no longer
   appears in the "contracted rates not locked" banner on the Contracted Rates page.
   (Combined with the earlier change, the banner now only shows LIVE, non-hidden
   projects.)

2. FOUR NEW MANDATORY FIELDS for a project to count as "details complete" (shown in the
   banners on Project Financials and Retention, and in the live banner at the top of
   Edit Project Details):
     - Site address
     - Order reference
     - Company name
     - Company address
   These read the resolved value (IHM value, or your override), so a project is complete
   if the detail exists either from the IHM or entered here.

after deploy + one refresh/sync. Some existing projects will now show incomplete until
