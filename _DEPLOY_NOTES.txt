WHAT'S NEW
  A new "12-Month" tab in Business Financials. Monthly forecast across the next 12
  calendar months, using the SAME sources as the 13-week view but in MONTHLY buckets:
    IN : invoices owed, retention releases, VAT refunds, project-cash-flow forecast
         sales, manual lumps (in)
    OUT: bills, overheads, commitments, VAT payments, CIS to HMRC, project-cash-flow
         forecast costs, manual lumps (out)
  Net + running closing balance per month, a chart, and a 12-month totals row.

  GAP-FILL OVERLAP: same as the 13-week view - a project's forecast sales/costs are
  suppressed in any MONTH where a real invoice/bill for that project exists, so the
  forecast only fills the gaps.

  MANUAL LUMPS: add revenue / labour / materials / other for future work you don't yet
  have a project or invoice for. Each lump: In/Out, category, month, amount, comment.
  Saved automatically (config:cashflow-lumps) and folded into the month it's assigned.

NOTE: relies on Phase A being deployed (project tracking on bills + projForecasts in
the API). Re-sync bills so the cost-side overlap matches, same as Phase A.
