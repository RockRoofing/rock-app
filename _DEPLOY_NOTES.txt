WHAT'S NEW
  A "No. of Visits" column has been added to the project planner, immediately AFTER the
  "Contract Compl." column. It counts automatically for each project.

HOW A VISIT IS COUNTED
  - Only days marked ACTUAL with someone on site count (planned / provisional days are
    ignored - so the count reflects what really happened).
  - Visit #1 = the first programmed (actual) day on site.
  - A NEW visit is counted each time the project leaves site for 2 OR MORE WORKING DAYS
    and then returns. Normal weekends are ignored (Fri then back Mon = same visit, not a
    new one). A gap of 2+ working days (e.g. on Monday, off Tue+Wed, back Thursday) counts
    as a new visit.
  - Shows "-" until there are actual on-site days.

  It updates automatically as you confirm days as Actual on the gantt - nothing to enter.
