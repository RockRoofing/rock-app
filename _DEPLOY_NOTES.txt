DEPLOY NOTES - Site App: "Back to forms" really returns to the forms list
=========================================================================

THREE files, all EDITS - just replace them.
  pages/forms/index.js    (forms list is now a real URL state)
  pages/forms/fill.js     (Back to forms goes to the list)
  pages/forms/browse.js   (tags forms opened from the CM browse list)

WHY THE FIRST FIX DIDN'T WORK
  On the Site App the forms LIST isn't a separate page - it's a "mode" inside the
  /forms home screen. So going back just reloaded /forms, which always opens on the
  HOME menu, not the list. router.back() couldn't help because there was no separate
  list URL to return to.

FIX
  - The home screen now records the current view in the URL (/forms?mode=forms for the
    forms list, ?mode=drawings, ?mode=rams). Returning to that URL restores the list
    instead of the home menu.
  - "Back to forms" on a form now goes to the forms list:
      * opened from the operative forms list -> /forms?mode=forms
      * opened from the CM browse list       -> /forms/browse
  BUILD: next build -> Compiled successfully.
