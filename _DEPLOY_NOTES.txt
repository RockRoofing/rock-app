ON THE PDF
----------
Summary block, under Materials On Site:

    1st Release Retention        £2,925.00      £2,925.00
    2nd Release Retention        £2,925.00      £2,925.00

Certificate block, between Retention and Total:

    Retention (3%)               £5,850.00
    Retention released           £5,850.00
    Total due                  £195,000.00

The certificate row matters most: without it the Total on a document going to the customer
would not add up from the lines above it, and that is the first thing anyone checks.

A half that has NOT been claimed is not printed. An unclaimed release is a nil line on a
claim document, and this is read as a claim rather than a checklist.


A BUG CAUGHT BEFORE IT SHIPPED
--------------------------------
The PDF recalculates the certificate from scratch, and it was not being given the PREVIOUS
application. Without that it cannot tell which half was already claimed, so it counted
both again:

    with the previous application     this certificate releases £2,925
    without it                        this certificate releases £5,850

The screen was already right - pkg473 passes it there - so the PDF would have disagreed
with what the QS was looking at, on the document that goes out. Now passed to both the
download and the emailed copy, so all three agree.
