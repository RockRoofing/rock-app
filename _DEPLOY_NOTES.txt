WHAT THIS DOES
  Five working Design pages, all sharing one shell (purple sub-nav + project picker):
    - Warranties, O&Ms, Calculations, Leak Test Certs: upload / list / view / download.
    - Tech Sub: viewer of the current submission at the top, table of versions below.
      Uploading a NEW Tech Sub automatically marks the previous one as "Revised"; you
      can also "Make current" an older one.
  Files upload directly to storage (handles very large docs).

  ACCESS RULES (enforced server-side in design-files API):
    - Internal (Designer / Post-Contract / Management / Admin): upload, view, download,
      delete.
    - External customers: VIEW & DOWNLOAD ONLY, and ONLY for the projects they are
      scoped to. Any request for a project they aren't assigned is rejected.

  Each page has a project picker showing only the projects the user may access
  (all projects for internal; scoped list for customers).
