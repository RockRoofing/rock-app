1. MARK DONE FROM THE TABLE
----------------------------
New tick box at the start of each row. Click it and a window opens:

  WHAT HAPPENED?     a proper text box for call notes, email summary, outcome. Saved to
                     the project's history against that activity, so the record of the
                     conversation sits where anyone looking at the deal will find it.

  SET THE NEXT ONE   description, due date and person responsible, pre-filled with today
                     and the current owner.

Three buttons: Cancel, "Just mark done", and "Done & set next".

The follow-up prompt is deliberate. Marking something done is the moment you know what
happens next, and a project with nothing booked is how deals go quiet - it is also exactly
what puts the warning triangle on the kanban. You can still skip it with "Just mark done".


2. THE ACTIVITY COLUMN IS EDITABLE
-----------------------------------
Click the activity text and a large window opens with a full-size box for the description -
nine rows, resizable - plus due date and person responsible. Notes about a call or an email
need room, not a single line squeezed into a table cell.


HOW IT SAVES - THE FIDDLY BIT
------------------------------
An activity lives in one of two places depending on where it came from:

  imported from Pipedrive  ->  its own per-deal store
  added inside the CRM     ->  on the deal itself

Both are handled. The code works out which one it is and takes the right route, so it
behaves identically whichever you are looking at. Verified both paths route correctly.

Activities you create through "Done & set next" are saved on the deal, so they appear in
the table immediately and on the deal's own activity list.
