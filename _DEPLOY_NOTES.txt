1. OPEN PROJECTS AND OPEN ACTIVITIES ONLY
------------------------------------------
The table was listing activities against every deal regardless of status, so work on jobs
won or lost months ago was sitting in the list and inflating the overdue count. It now
skips any activity whose project is not open.

Completed activities were already excluded by default; that is unchanged, and the
"Include completed" tick box still shows them for the open projects if you want the
history.

So the list is now: outstanding activities, on live projects. Which is what makes it a
usable to-do list rather than a nine-year archive.

Expect the overdue number to drop noticeably - that drop is the noise coming out, not
activities going missing.


2. THE MISSING SCROLLBAR
-------------------------
Real bug, and mine. The page body is a fixed-height flex container with overflow: hidden:

    <div style={{ flex: 1, minHeight: 0, overflow: 'hidden', ... }}>

The existing List, Companies and Contacts views each handle their own scrolling inside
that. My Activities table did not - it just grew tall, and everything past the bottom of
the window was unreachable with no scrollbar to get to it.

FIXED: the table now has its own scroll area, so it behaves like the other tabs.

WHILE I WAS THERE: the header row is now sticky. Scroll down a long list and the column
names stay visible, so you can still tell which column you are looking at - same as the
H&S matrix.
