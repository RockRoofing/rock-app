URGENT - pkg428/429 broke the build. This is the fix.


THE ERROR
---------
    ReferenceError: useMemo is not defined
    Error occurred prerendering page "/scorecard-crm"

pkg428 added a useMemo for the deal lookup and I never added it to the React import. The
file still read:

    import { useState, useEffect } from 'react'

Now:

    import { useState, useEffect, useMemo } from 'react'


WHY MY BUILD CHECK MISSED IT
----------------------------
`npm run build` here COMPILES the page but does not PRERENDER it. Vercel does, and that is
when the missing hook is actually called. So it passed locally and failed on deploy - the
same blind spot as the runtime ordering fault in pkg407.

I have added a sweep for it: every page and component is now checked for React hooks used
but not imported. Ran it across the whole app - everything else is clean.
