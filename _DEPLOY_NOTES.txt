WHAT CHANGED
-------------
1. THE DRILL-DOWN NOW REPORTS THE FIGURE ON THE ROW, IT DOES NOT INFER IT.

   A new first line in the Gross AFA section:

       SHOWN ON THE ROW    140,274.20    application 2 (sent)

   Read straight from the value the column renders, with the route beside it. No
   caption anywhere else in that section can contradict it.

2. The stamp line is retitled "Figure saved when it was sent" and now keys off
   whether the stamp was actually USED, not whether it exists. On J228 it will read
   "NOT used. Out of date - the application was edited after sending. Re-send to
   bring it back into line."

3. "Where the records live" said "0 on id, 0 on job no" on a project with two
   applications. The counters were only set on the merge path, so any project whose
   applications sit on ONE record reported zero for both - a diagnostic saying
   nothing while looking like it said something. Counted before the early returns
   now. J228 should read "2 on id, 0 on job no".
