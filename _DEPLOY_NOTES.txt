WHAT IT IS
----------
An exact copy of the Scorecards page reading from the CRM instead of the Pipedrive sync.
Same pattern as Sales (CRM): both pages sit side by side, you compare, and when you trust
the numbers the old one goes.

New tab in the Pre-Contract nav: Scorecards (CRM), right after Scorecards.

It is byte-identical to pages/scorecard.js apart from four things:
  - reads /api/deals-crm instead of /api/deals
  - green comparison banner at the top
  - page title says (CRM)
  - no "Sync now" button, because there is nothing to sync - the CRM is the source

No API work was needed. /api/deals-crm already existed and already returns exactly the
same shape as /api/deals, via lib/crmDashboardAdapter. Nothing on the live Scorecards page
is touched.


ONE HONEST CAVEAT - READ THIS BEFORE COMPARING
-----------------------------------------------
Only the DEAL data comes from the CRM. Three of the metrics are built from
/api/value-changes, which is Pipedrive sync data and has no CRM equivalent:

    Total value of work priced
    Value priced - existing customers
    Projects priced over 200K

Those will read IDENTICALLY on both pages. That is not the comparison working - it is the
same number twice. Ignore them when you are checking.

The metrics genuinely worth comparing are the ones built from deals:

    Strike rate (overall)                    Glenigan enquiries received
    Strike rate (MC Secured/Negotiating)     Glenigan enquiries priced
    Total value of work secured              Glenigan scored 5+
    Deals secured over 200K                  Projects secured over 200K

If those match across both pages, the CRM is a sound replacement for the Pipedrive feed.
If they do not, the difference will be in the adapter or in what got imported, and the
detail is in the drill-downs on each card.

GP margin is unaffected either way - it comes from Xero via /api/dashboard on both pages.
