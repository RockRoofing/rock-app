pkg460 - open a project in a new tab
====================================

Deploy after pkg459. One changed file: pages/crm.js. No new files.


WHY IT WAS NOT POSSIBLE
-----------------------
The rows used onClick handlers, not links. A browser can only offer "Open in a new tab" on
an actual anchor, so right-click gave nothing, and neither did ctrl-click, cmd-click or
middle-click.

The deep link already existed - /crm?deal=1234 has worked since the mention emails were
built. Nothing was pointing at it.


WHERE IT WORKS NOW
------------------
    Activities tab   the Project column
    List view        the Title column
    Pipeline         the title on each card

All three are ordinary links now, so every gesture your browser normally offers works:
right-click menu, ctrl or cmd click, middle click, shift for a new window, and dragging
the link to the tab bar.

A PLAIN left click behaves exactly as before - it opens the project in place, no page
reload. Only modified clicks are handed to the browser.


ONE DELIBERATE LIMIT ON THE PIPELINE CARDS
--------------------------------------------
Only the TITLE is a link, not the whole card.

The card is draggable. If the drag surface were an anchor the browser would try to drag
the LINK - offering to drop a URL somewhere - instead of moving the deal between stages.
The rest of the card still opens the project on a normal click, so the only thing you lose
is right-clicking the blank part of a card.

Same reasoning in List view: the title cell is the link, the rest of the row keeps its
click handler.
