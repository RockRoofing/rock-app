FIX 1 - "L:J203" style codes on the report
When a project could not be found in the current project list (e.g. old/test/removed jobs),
the report showed the raw key like "L:J203". It now strips the prefix and shows just the
project number ("J203"). Real, current projects continue to show their proper name; this only
affects ones no longer in the project list.

FIX 2 - Overheads multi-day now works like projects
The Overheads row no longer opens a single-day panel with a long list of dates. Instead it uses
the SAME drag-to-select as the project rows:
  - In Day view, click/drag across the Overheads row to select one or more days.
  - The action bar appears ("Overheads - N days selected") with "Add / edit overheads".
  - That opens a panel to add staff + category to ALL selected days at once, and to see/edit
    who is already on overheads for each of those days.
No more big in-modal date checklist - it matches how you allocate projects.
