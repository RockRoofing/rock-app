PROBLEM
Every action on the Planning gantt (allocating operatives, closing the allocate modal, the
water-ingress modal) triggered a full-screen "Loading..." for a few seconds, because those
actions called the full page loader (which refetches everything and blanks the screen).

FIX
Those actions now refresh the data IN PLACE, without the loading screen - the gantt updates
instantly and stays where you are (no scroll-to-top, no blank). The full loader now only runs
ONCE, when you first open the page (which is correct).

A new "full" in-place refresh covers everything the allocate / water-ingress modals can change
(allocations, operatives, RAMS signing, competency) - so the picture stays accurate after you
add an operative or sign RAMS, just without the flash.

NOTHING else changes - same data, same behaviour, just instant.

NO vercel.json change. No cron. BUILD: Compiled successfully.
