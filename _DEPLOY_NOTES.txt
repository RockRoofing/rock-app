THE CHANGE
===========
The persistent add-row at the top of the Variation Tracker table is gone. It was a
row of empty inputs sitting directly above the data, led by a project dropdown and
a box reading "Description" - which is a reasonable thing to read as a search bar.

Add Variation now sits at the right-hand end of the filter box, and is a good deal
bigger: 15px bold, 11px by 22px padding, against 13px and 7px by 16px before. It
opens the same modal the nav button always did, so nothing about adding a variation
has changed except where you press.


ONE BUTTON, ONE PLACE
----------------------
There were three ways to add a variation and now there is one.

  - the nav button, top right                  REMOVED
  - a duplicate in the embed header            REMOVED
  - the inline row                             REMOVED
  - the filter box button                      the one that remains

The embed had its own copy because the nav is not rendered there. The filter box
is, so a single button now serves both and there is no second copy to drift.


DETAILS WORTH KNOWING
----------------------
The button is pushed right with marginLeft: auto rather than a spacer, so it still
lands at the right-hand end when the filters wrap onto a second line on a narrow
screen.

The inline row's state and its save function are removed as well, not just the
markup - inlineAdd, inlineSaving, inlineProject, saveInlineAdd and the inlineCell
style. Dead code that still writes variations is worth deleting rather than
leaving for somebody to find later and wonder about. The modal's save path is
untouched and was always the same one.


ALSO IN THIS PACKAGE

pkg812: a search box in the CRM deal's top bar. Opening a deal replaces the whole
page, so the toolbar search disappears and getting between projects meant going
back to the list. Matches on the same rule as the rest of the CRM, ranks title
matches above buried ones, includes won and lost, excludes the deal you are in.
