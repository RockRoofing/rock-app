THE CHANGE
===========
A tag is a tag. Whoever is named gets the email, including you when you tag
yourself.

The rule that suppressed it came over from the CRM, where the reasoning was that
nobody needs an email telling them what they just typed. That holds for a running
note on a deal. It does not hold here - tagging yourself on a mis-coded cost is a
deliberate act, usually to put it in your own inbox to come back to, and dropping
it silently is just surprising.

Verified:

  cost comment, tag self          -> James McVeigh
  cost comment, tag self + other  -> James McVeigh, Dori Balog
  cost comment, tag other         -> Dori Balog

The composer footer now says so: "Tag yourself and you get one too."


THE CRM IS DELIBERATELY UNCHANGED
-----------------------------------
notifyMentions() takes notifyAuthor, defaulting to true. The CRM's
sendMentionEmails() passes false, so CRM notes behave exactly as they always have.

Verified: CRM note, tag self -> nobody emailed.

I have not changed the CRM because you asked about cost comments and the CRM rule
was put there on purpose. If you want it to match - tag yourself in a CRM note and
get the email - it is one word, deleting `notifyAuthor: false`. Say so and it goes
in the next package.


IF IT STILL DOES NOT ARRIVE
-----------------------------
The comment will now tell you which case you are in rather than saying "Saved."
(pkg808). The ones to watch for:

  "Email is not configured on the server (RESEND_API_KEY is not set)"
      -> nothing will ever send until that env var is set in Vercel

  "did not send" followed by Resend's own words
      -> almost always an unverified sending domain. FORMS_FROM_EMAIL defaults to
         onboarding@resend.dev, which Resend will only deliver to the account
         owner's address

  "Nobody is taggable here"
      -> the portal user records have no email address, or no post-contract /
         management / admin role. Fixed in user admin, not in code

And check junk - the from address is whatever FORMS_FROM_EMAIL is set to.
