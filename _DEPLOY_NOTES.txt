IT WAS ALREADY ON THE SCREEN - JUST NEVER NAMED
------------------------------------------------
Your J190 materials panel reads claimed 240,772 and spend 165,030. THAT 75,742 GAP
IS THE AWAITING-INVOICE FIGURE. It has been sitting there as two unconnected
numbers the whole time.

So this is not a new calculation, it is naming one you already had. Both the
Labour and Materials panels now carry a line:

    Not yet invoiced (claimed less spend)     £75,742
    expected still to be invoiced to us

NOT in materials on site, which would have been wrong - that box is materials
CLAIMED on the application, an asset you have billed the customer for. This is the
opposite: cost you have incurred that your supplier has not billed YOU for.


EDITABLE, BECAUSE ONLY YOU KNOW WHICH IT IS
-------------------------------------------
A gap is either a subcontractor who has not invoiced yet, or work that was never
done and should be written off. The app cannot tell those apart.

Blank uses claimed less spend. Type a figure and it says "overridden - calculated
is 75,742" so a decision never looks like the default.

    claimed 240,772, spend 165,030, no override  ->  75,742
    override 0                                    ->       0  (written off)
    override 20,000                               ->  20,000
    labour OVERSPENT (79,496 vs 94,703)          ->       0

That last one matters: it shows nil rather than a negative. You cannot be owed an
invoice for cost you have already paid more of than you claimed.


IT IS STORED ON THE FORECAST
----------------------------
Which scopes it to the position at that valuation. Redo the forecast after the
next application and it starts clean rather than a write-off silently suppressing
a later, genuine shortfall - exactly as you described your workflow.


AND THE 13-WEEK HONOURS IT
--------------------------
Where you have set a figure, the cash flow uses it instead of recomputing. It
already sweeps this into the current week inside the "Overdue - brought forward"
row, so nothing is left in a month that has gone. Recomputing it there would have
quietly overruled you.
