1. EXPORT TO EXCEL
------------------
An "Export to Excel (142)" button at the right of the filter bar, on Costs (Bills), Sales
Invoices, Direct Wages and Overheads.

It exports WHAT IS ON SCREEN, not the whole tab. The filters are the point of this page -
a month, a supplier, a code - and exporting everything regardless would mean redoing that
work in Excel, and would produce a different answer from the totals shown above the table.

Columns: Date, Reference, Supplier, Description, Project, Account code, Account name,
Category, Assigned, Amount. Widths set so nothing is a column of hashes.

A TOTAL row at the bottom, so the file agrees with the screen at a glance.

The filename says what it is and what it was filtered to:

    Costs (Bills) - 2026-08 - SIG.xlsx

Disabled when the filters leave nothing to export, rather than producing an empty file.


2. THE RETENTION TAB IS NOW VIEW-ONLY
---------------------------------------
Removed from the embedded view:

    + Add Manual Entry          Bookkeeping views this register, it does not maintain it
    Import spreadsheet          same
    Project links on the refs   no route out into Project Financials
    "Project details incomplete" banner

That last one is worth explaining: it is a row of links INTO projects, prompting somebody
to go and fix them. That is work for the commercial team, and every link on it was a way
out of the read-only view.

The full page at /retention is unchanged - everything still works there for whoever owns
it.
