WHAT THIS DOES
  The Lessons Learnt portal page now has two tabs:

  1. LESSONS TABLE - every lesson auto-collected from the minutes, each tagged with one
     or more departments (Estimating / Commercial / Operations / Accounting / Sales).
     Search by text and filter by department. You can tweak a lesson's departments
     (click the chips), add a manual lesson, or delete one. New/blank-department lessons
     are auto-categorised by the AI layer (see AI note below).

  2. MONTHLY MINUTES - a month-by-month table (month + meeting date + status). Open any
     month to edit the minutes. All sections from your spreadsheet are here: Wins,
     General performance / KPIs, Up and coming news, Big focus, Lessons Learnt, and
     Meeting actions (action + person responsible). Drafts AUTOSAVE as you type. Click
     "Meeting complete" to lock the minutes and push that month's Lessons Learnt lines
     into the table (auto-categorised).

  SEEDED HISTORY: on first load it seeds 20 months of your past minutes (Sept 2024 ->
  June 2026, all marked Complete) and 132 categorised lessons into the table. Where a
  month had separate Office + Operatives tabs, they've been merged into one set of
  minutes using the latest format. Meeting dates were not in the sheet - set them per
  month when you like.

AI LAYER
  Department categorisation uses the Anthropic API when ANTHROPIC_API_KEY is set in your
  Vercel env vars, with a keyword-based fallback if it isn't (so it always works). The
  132 seeded lessons were categorised by the keyword rules; you can refine any of them by
  clicking the department chips. New lessons added going forward will use the AI.
  -> To enable the AI: add ANTHROPIC_API_KEY to Vercel env vars. Optional but recommended.
