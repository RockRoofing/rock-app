THE CRASH
---------
The new reconciliation cell called gbp() NINE times. There is no gbp() in
retention.js - that file uses fmt() and fmtC(). I carried the name over from
pages/project-cashflow.js, where gbp() does exist.

It compiled perfectly and threw ReferenceError on the first render, taking the
whole page down. Exactly the failure mode your notes warn about: an undefined
identifier passes the build and only shows up at runtime. Same shape as the
fmtD() one I caught during the build on the cash flow position panels - that one
I spotted before shipping, this one I did not.

All nine now use fmtC(), which is what the rest of the file uses.

I also scanned every file touched across these packages for the same class of
fault - a helper borrowed from another page and never declared or imported
(gbp, gbpK, fmt, fmtC, monthShort, INK, isoOf, pad). retention.js was the only
one. The unicode escapes are single-backslash and render as real glyphs, checked
separately.
