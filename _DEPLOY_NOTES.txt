IMPORTANT - MAKING THE FORMS APPEAR IF THEY AREN'T ALREADY
  Seed forms only auto-load when the forms store is completely empty. Since the app
  already has forms saved, if these H&S forms are not already showing you need to run a
  ONE-OFF additive seed (it adds only missing forms, does NOT touch or overwrite any
  form you've edited):

    Send a POST to /api/forms with body:  { "action": "seed-missing" }

  Easiest way: open the site while logged in, then in the browser console run:
    fetch('/api/forms',{method:'POST',headers:{'Content-Type':'application/json'},
      body:JSON.stringify({action:'seed-missing'})}).then(r=>r.json()).then(console.log)
  The response lists which form ids were "added". Refresh the Forms list to see them.

  (If they already appear in your Forms list / Form Builder, no action needed.)
