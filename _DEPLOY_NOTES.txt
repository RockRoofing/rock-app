pkg736 - The missing invoices sync
===================================

DEPLOY OVER pkg735. Two files.

REPLACE:
  pages/business-financials/invoices.js
  pages/business-financials/cashflow.js

WHAT THE MARKER TOLD US
------------------------
  116 rows in the store, 0 TYPED, last synced 21/07/2026.

Zero typed is the whole story. lib/xero.js stamps `type` on every row, and that
stamp went in as part of the SAME fix that moved Type=="ACCREC" into the WHERE
clause. A store where nothing is typed was written BEFORE that fix - by the
version using the bare Type= parameter that Xero ignores.

So those 116 rows are exactly the ones that can contain supplier bills.

MY pkg734 REASONING WAS WRONG
------------------------------
I argued "provenance is the guarantee - this store is only written by
fetchOutstandingReceivables, so whatever is in it is a receivable."

Provenance only guarantees anything if the code that wrote it was correct. This
store was written six weeks ago by pre-fix code. My normalise stamps all 116
rows ACCREC and passes them through, bills included. That is why you are still
seeing supplier invoices as customer invoices.

The store is not trustworthy. It has to be rewritten.

THE FIX
-------
A "Sync outstanding (cash flow)" button on Invoices Owed, next to the existing
one. Blue, so the two are not confused.

  Sync invoices from Xero      -> invoiced:lines:  (Invoices Owed table, WIP,
                                                    margins, commercial)
  Sync outstanding (cash flow) -> bank:outstanding-receivables  (both cash flows)

The Bills page has always had its equivalent. Invoices never did, which is why
that store was last written on 21 July and nothing in the app could refresh it.
The endpoint already existed - there was simply no button.

PRESS IT ONCE AFTER DEPLOYING. That rewrites all 116 rows with the current
fetch: ACCREC in the WHERE clause, a defensive post-filter on inv.Type, and a
type on every row. Supplier bills cannot survive it.

The marker now also tells you when the store is untyped rather than just
printing "0 typed", so this cannot sit unnoticed again.

WHAT TO CHECK AFTER PRESSING IT
--------------------------------

  2. The untyped warning should be gone.
  3. Overdue - brought forward: no supplier names in the green rows.
  4. The swing between -500k and +500k should be gone.
  5. The invoices-owed total should tie to Xero's Aged Receivables.

If it still shows bills AFTER a fresh sync, then lib/xero.js is still wrong and
that is a different fix - tell me and I will look there rather than at the store.
