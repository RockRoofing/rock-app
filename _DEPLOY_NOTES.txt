1. DESIGN HANDOVER CHECKLIST - ADDED
-------------------------------------
At the END of the Design Handover Checklist section, exactly as your screenshot:

  "ESTIMATOR - If available, has the following information been added to file
   8. Design > 1. Design Handover Docs?"

     Latest Roof Plan / Elevation Mark-Up
     Latest tapered drawing
     U-Value Calcs
     Wind Load Calcs
     Rainwater Calcs
     Mansafe Sketch
     Latest Technical Submittal including separate docs
     Contract Drawings          <- the extra one you asked for (the red row)

  followed by "Anything else that needs adding?" as a free-text box.

Each row ticks Yes / No / N/A. There is a "Mark all Yes" shortcut at the top, and pressing
an already-selected answer clears it. Answers are stored against the item TEXT rather than
a position, so re-ordering or inserting items later will not shuffle existing answers onto
the wrong rows.

This needed a new field type ('checklist') since the IHM had no fixed tick-list before. It
is wired into the form and the read-only project view. Any future checklist can now be
added to the schema alone.
