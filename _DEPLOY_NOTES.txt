DEPLOY NOTES - IHM: guidance to keep the project number out of the name
======================================================================

ONE file, an EDIT - just replace it.
  lib/ihmSchema.js

CHANGE
  The Internal Handover Minutes "Project Name" field now shows guidance under it:
  "Enter the project name only - do NOT include the RR Project Number (it is captured
   in the field below). Adding the number here makes it show twice across the app."

WHY
  Ops/IHM-driven screens (Issues, Deliveries, Procurement, Risks, RAMS, reports) show
  the project as "<number> - <name>". If the number is typed into the IHM name too, it
  appears twice. Keeping it out of the name at source fixes all of those screens at once
  - no per-screen changes needed, nothing else touched.

  (This does not alter any existing data. Projects already saved with the number in the
  name will still show it until that IHM name is edited.)
