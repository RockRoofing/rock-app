MY BUG
------
I called getValidTokens(). There is no such function in that file - every other
handler uses getTokens(), imported from lib/db at line 2. So the call threw and
the error came straight back to the page as the message you saw.

Worse, my version had NO TOKEN REFRESH. Every working handler does:

    let tokens = await getTokens()
    try { const nt = await refreshXeroToken(tokens.refresh_token)
          if (nt?.access_token) { tokens = { ...tokens, ...nt }; await saveTokens(tokens) } } catch {}

Without it, an access token more than about half an hour old fails on every call -
so even with the right function name it would have worked once and then stopped.
Now mirrors the balances handler exactly.

A missing connection now returns 200 with ok:false, so the page shows the message
rather than the client having to interpret a 400.

I also swept the file for any other awaited call that does not resolve to an
import or a declaration. Only a dynamic import() came back, which is a false
positive.
