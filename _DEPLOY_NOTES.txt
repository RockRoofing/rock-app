pkg393 - edit and delete comments on notes
==========================================

Deploy after pkg392. One changed file: pages/crm.js. No new files.


WHAT YOU GET
------------
Every comment under a note now has Edit and Delete beside the author and timestamp.

  EDIT    turns the comment into a text box in place, with Save and Cancel. The full
          @mention autocomplete works while editing, same as writing a new one.
          An edited comment is marked "(edited)" next to the timestamp - so the history
          stays honest about what happened rather than quietly rewriting itself.

  DELETE  asks first, then removes it. The note and every other comment are untouched.

Saving an edit with the box emptied cancels rather than storing a blank comment. If you
want it gone, Delete says so plainly.


MENTIONS ON EDIT
----------------
If you edit a comment and ADD an @mention, that person gets the email. People already
mentioned before the edit do NOT get another one - re-emailing everyone each time a typo
is fixed would train people to ignore the alerts.


WHY THIS WAS FIDDLIER THAN IT LOOKS
-----------------------------------
Comments are not stored on the deal. They live inside the history entry of the note they
belong to, so both handlers walk history -> the note -> its comments rather than touching
history directly. Tested that editing and deleting a comment leaves the parent note's own
text and the sibling comments alone.

The comment thread renders in two places - inside HistoryItem and directly in the deal
view - so both were wired, not just the obvious one.
