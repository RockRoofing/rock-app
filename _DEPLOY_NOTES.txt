FIX 1 - CM on Project Financials / EOM was the WRONG source
The EOM report pulled the Contracts Manager from the project SETTINGS store, while
Ops -> Edit Project Details reads it from the IHM (Internal Handover Minutes). They could
differ. The EOM report now reads CM from the IHM first (same source as Edit Project Details),
falling back to settings only if the IHM has none. Matched by project number.

FIX 2 - Retention "Applied for" was always blank / manual
The "Applied for" column on the Retention register never pulled from applications - it was a
manual field. It now AUTO-POPULATES from the newest application on each project (the gross
applied-for total of the latest application by sequence). If you type a value in manually, your
value still wins (override).

IMPORTANT - cache refresh
The dashboard caches for up to 4 hours. This change bumps the cache marker so the FIRST load
after deploying rebuilds the cache with the corrected CM and the new applied-for values - no
manual sync needed. (If you want it instantly, the Sync button on Project Financials / Outstanding
Invoices also forces a rebuild.)

NO vercel.json change. No cron. BUILD: Compiled successfully.
