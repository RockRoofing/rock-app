WHAT IT DOES
------------
"See on map" appears beside Site Location in the Details panel of a deal,
whenever a location is set. It opens a map over the page.

Closes on the X or Escape ONLY - never on a backdrop click, same as every other
modal in the portal.

WHAT IT SEARCHES
----------------
Site location plus the postcode where one is recorded:

  "Kilburn Square, NW6 6PS"

The postcode matters. A site name on its own often lands on the wrong side of
town; with a postcode it lands on the building.

NO API KEY NEEDED
-----------------
An embedded Google map via maps.google.com/maps?...&output=embed, which needs no
key, no account and no billing setup. Nothing to configure and nothing to expire.

If you later want pins, satellite view or driving time from the yard, that needs
the paid Maps JavaScript API and a key - worth knowing before anyone asks.

TWO SMALL THINGS
----------------
"Open in Google Maps" at the foot, for directions on a phone.

A line saying it is a SEARCH location, not a surveyed position. It is a geocoded
guess from a text field, and somebody will eventually try to set out from it.
