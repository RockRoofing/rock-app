1. WHY THE SITE APP REPORT WAS NOT WORKING
-------------------------------------------
ROOT CAUSE: middleware.js. On the siteapp. host, only a whitelist of /api/* paths is let
through - everything else gets rewritten to /forms. `/api/report-problem` was never added
to that whitelist, so the Site App's POST was being rewritten to the /forms page instead
of reaching the API. It returned the HTML page, the JSON parse gave nothing useful, and
the report vanished. Nothing was ever saved.

This is the same class of problem as the note in the build rules: "New Site App API routes
must be in middleware.js passthrough or they're blocked."

FIX: added to the passthrough -
  /api/report-problem     the report itself
  /api/blob-upload        so Site App attachments can upload too

WORTH KNOWING: reports raised from the Site App before this deploy were never saved and
cannot be recovered - they were never written to the database. If anyone has been telling
you they reported something and you never saw it, that is why.
