pkg442 - retention tracker: scrollbar always in view, header frozen
===================================================================

Deploy after pkg441. One changed file: pages/retention.js. No new files.


1. THE HORIZONTAL SCROLLBAR
---------------------------
The table container had no height limit, so it grew to whatever length the table needed
and the PAGE scrolled instead. The horizontal bar therefore sat at the very bottom of the
table - you had to scroll past every row to reach it, move it, then scroll back up to see
what you had done.

The table area is now a bounded box: it fills the window down to about 300px from the top
and scrolls internally in both directions. The horizontal bar is pinned to the bottom of
the visible area and is always reachable, wherever you are in the list.

Minimum height 320px, so it does not collapse to nothing on a short window or a filtered
list of two rows.


2. FROZEN HEADER
----------------
Column headings stay put while the rows scroll under them. Sorting still works - they are
the same buttons.

Applied to each header CELL rather than the row, which matters: the table uses collapsed
borders, and with those the row's background and border do not travel with a sticky cell.
Done at row level the data would have scrolled straight through the headings. Each cell
now carries its own background and its own bottom border.


ONE THING I CHECKED AND DID NOT CHANGE
----------------------------------------
The white card around the table has overflow:hidden, which rounds the corners. I briefly
changed it, thinking it would capture the sticky header - then checked properly. It does
not: the scroll box inside has overflow:auto, so that is the nearest scrollport and the
header sticks to it. Reverted rather than leave a less widely supported CSS value in for
no benefit.


WORTH KNOWING
-------------
The 300px allowance covers the page header, the filter bar and the summary tiles. If you
add anything above the table later, that number needs adjusting or the bottom of the box
will sit off-screen. It is one line near the top of the table block.
