WHAT THIS IS
  The Calculations page is now EXACTLY the same as Rock Drawings, but for calculations:
  thumbnails, revisions (greyed superseded cards behind the current one), In Review ->
  Approved (customer approves), Construction Issue (Rock Roofing only), mark superseded
  (requires uploading a new revision), View / Add Comments viewer (comments at the top,
  @mentions notify, X-only close), Notify project users (with approver picker), Download
  all / selected (zip), bulk "Approve selected" for customers, and the full approval
  evidence (append-only audit log + SHA-256 file fingerprint + timestamped certificate PDF).

  It uses its own separate storage, so Calculations and Rock Drawings never mix.
