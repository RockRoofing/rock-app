WHAT THIS VERSION ADDS
----------------------
It reads the dashboard snapshot purely to label each record with its job number
and name, and to answer the question that actually matters:

    orphan: true   this key is NOT a live Xero tracking option

An orphan record cannot be selected anywhere in the portal, because every
project picker is built from the live list. But anything that scans every
project:* key still counts it - and the applications summary does exactly that.

That is precisely the shape of what you described: it shows in the table, and
the project cannot be found.

New fields in the response:

    liveProjectsInSnapshot                  how many the portal can actually see
    orphanRecords                           how many records are not among them
    orphansHoldingApplicationsOrVariations  the ones that matter - unreachable
                                            records still holding work
    liveJobNo / liveName / liveStatus       on every record, so the full list is
                                            readable
    orphan                                  on every record
