pkg305 - CRM import: skip activities/notes for deals not in the CRM
====================================================================

REPLACES pkg302, pkg303 and pkg304. Deploy this one only.

CHANGED FILES
-------------
  lib/crmImportMap.js     both export formats + activities/notes mappers
  pages/api/crm.js        per-deal storage, per-deal summary, get-sub
  pages/crm.js            orphan guard + board summary + per-deal loading

No new files. All straight replacements.


WHY THIS MATTERS NOW YOU HAVE REMOVED THE OTHER PIPELINES
-----------------------------------------------------------
The activities and notes exports still contain records for every pipeline. With your deals
now Project-only, those records point at deals that no longer exist in the CRM.

Before this change they would still have been written - to keys nothing ever reads, because
a note is only loaded by opening its deal. No error, nothing on screen, just several
thousand dead records accumulating on every re-import.

Now anything whose deal is not in the CRM is skipped, and the import tells you how many.

Simulated against a Project-only deal set (6,860 deals):

  activities   36,824 mapped -> 32,564 kept across 5,415 projects
                              4,260 skipped (deal not in the CRM)
                              2,577 skipped (not linked to any deal)

  notes        11,499 mapped -> 10,232 kept across 5,542 projects
                              1,267 skipped (deal not in the CRM)
                                869 skipped (not linked to any deal)

Those numbers match the pipeline breakdown exactly, so nothing Project-related is being
dropped by mistake.


IMPORT ORDER IS NOW ENFORCED
-----------------------------
Activities and notes are matched against the deals already in the CRM, so DEALS MUST GO IN
FIRST. If you try it the other way round you get a clear message rather than a silent
half-import:

  "Import your Deals export first - activities and notes attach to deals, so there is
   nothing to attach these to yet."

And if a file turns out to match nothing at all, it says so instead of reporting success.

If you re-import deals later, re-run activities and notes afterwards.


EVERYTHING ELSE FROM THE EARLIER PACKAGES IS STILL HERE
--------------------------------------------------------
  - Pipedrive's new unprefixed export format (this was why all five files were refused);
    the old prefixed format still works too
  - activities and notes import at all, stored per deal
  - the board's activity dot reads a small per-deal summary (234KB, not 31MB)
  - opening a deal loads its own activities and notes into the view and History

STILL TRUE: every activity in your export is marked Done (39,401 of 39,401), so the kanban
warning triangles are accurate and will remain after import. That is the export, not the
CRM.
