pkg437 - applications now pull retention AND MCD from the project
=================================================================

Deploy after pkg436. One changed file: pages/api/applications.js. No new files.


YOU WERE HALF RIGHT
-------------------
MCD was not pulling through. But retention was not either, quite - it only worked if
somebody had typed it into Edit Project Details.

Applications read the RAW project settings and never resolved through the IHM. Those
settings only hold retention and MCD once they have been entered in Commercial. So a
project handed over properly, with both recorded on the IHM, but never opened in Edit
Project Details, produced applications with:

    retention  5%   <- a hard-coded default, not the project's figure
    MCD        0%   <- nothing

The 5% is the worse of the two, because it looks like a real answer.


FIXED
-----
Both now resolve the same way everything else in the app does:

    Commercial override  ->  IHM  ->  nothing

Applied when the application list loads AND when a new application is created, so an
application picks up the right figures whether or not anyone has been into Commercial.

Tested:
    IHM only, never edited in Commercial   -> retention 3%, MCD 2.5%
    Commercial override beats IHM          -> retention 5%, MCD 1.25%
    Commercial MCD 0 beats IHM 2.5         -> MCD 0%   (a deliberate zero wins)
    No IHM, nothing set anywhere           -> retention 0%, MCD 0%


ONE BEHAVIOUR CHANGE WORTH KNOWING
------------------------------------
Retention no longer defaults to 5% when nothing is set. It defaults to 0%.

A guessed 5% is indistinguishable from a real 5%, and it silently deducts money from every
certificate on a project nobody has configured. 0% is visibly wrong and gets corrected;
5% just quietly happens.

If a project genuinely is 5%, it should be on the IHM - and now that it flows through, it
will be.


EXISTING APPLICATIONS ARE UNTOUCHED
-------------------------------------
This changes what a NEW application starts with, and what the list page shows as the
project's rates. Applications already created keep the mcdPct and retentionPct they were
saved with - deliberately, since changing a sent certificate retrospectively would be
worse than leaving it.

If an existing draft has the wrong figures, the fastest fix is to set them on the
application itself.
