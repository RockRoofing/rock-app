NEW - LABOUR CLASH DETECTION ON SHIFT
  Moving a project can land its operatives on days they're already booked on OTHER
  projects. The move is still APPLIED (as agreed), then a red banner appears at the
  top of the page listing every clash:
        <Operative name> on <date> - also on <other project>
  using the same rule as normal allocation (a same-day double-booking is only OK if
  both are half-days). Dismiss the banner with the x once you've reallocated the
  clashed days.

  This means you can reschedule freely and immediately see exactly which labour needs
  sorting, rather than creating silent double-bookings.
