THE DATE PICKER PROBLEM
-----------------------
The bills list is SORTED BY planned payment date (line 1224), and the input
committed on every change. So scrolling the picker from August to September wrote
a September date immediately - the list re-sorted, the row jumped somewhere else,
and the calendar closed on a date you had not chosen.

The date is now held as a local draft and committed only on BLUR:

  scroll Aug -> Sep    0 commits, row stays put
  pick the 15th        0 commits
  click away           1 commit, 2026-09-15

Two commits became one, and nothing moves while the picker is open.

Enter commits, Escape abandons the edit and puts the old date back.

THE SAME TREATMENT ON EXPECTED PAYMENT DATES in the Invoices owed table - same
fault, same fix, and it still writes straight to invoice:meta so the Invoices Owed
page follows.

One detail: the draft only follows the saved value when the field is NOT being
edited. Otherwise a save happening elsewhere would overwrite what you were part
way through typing.


ALSO IN THIS PACKAGE (pkg627)
-----------------------------
BALANCE SHEET TAB - reads every account from Xero's Balance Sheet report, grouped
by Xero's own sections, with NO account codes assumed anywhere. Track the ones you
want, set outstanding / per month / day / from / to, and they feed the forecast.

"Clears in" turns RED when the schedule will not clear the balance.

FINANCING & TAX column replaces "Vehicles / commitments" and carries both.
Payments STOP when the liability clears: 12,000 at 5,000/month gives 5,000, 5,000,
2,000 - not a fourth full payment.

RECONNECT XERO before using the balance sheet read - it needs
accounting.reports.balancesheet.read, which does not apply to an existing
connection.
