WHY YOU COULD NOT TYPE IN IT
----------------------------
    <input type="number" value={settings.drawn} ... />

settings.drawn is the NUMBER 0, so the box renders a literal "0" that cannot be
cleared - you end up appending digits after it. The new box starts EMPTY with a
"0.00" placeholder.


DRAWN IS NOW A DATED SERIES
---------------------------
A drawn balance is a point-in-time reading off a Bibby statement, not something
the app can know. Overwriting one number meant it went stale silently, and a
figure typed in March looked identical to one typed this morning.

Now: pick the date it applies to, enter the amount, press Add. Every reading is
kept and THE MOST RECENT BY DATE is the one used.

Underneath: "Using GBP 122,711.31 as at 29/08/26 - 3 readings", with the last few
listed and an x to remove any of them.

Checked:
  add 30/06 98,000            -> uses 30/06
  add 29/08 122,711.31        -> uses 29/08
  add 31/07 110,500 (back-dated, out of order) -> still uses 29/08, correct
  re-enter 29/08 125,000      -> REPLACES it, does not stack two readings for
                                 one day, which would make "most recent" ambiguous
  remove 29/08                -> falls back to 31/07

Stored in its own key, config:if-drawn-history. The old single `drawn` setting is
still read as a fallback so nothing entered before this is lost.


THIS SHOULD CLOSE THE AVAILABILITY GAP
--------------------------------------
Your last export had BOTH of these at zero:

    High involvement    0.00   should be  35,069.31
    Funds in use/drawn  0.00   should be 122,711.31

The app computes availability = approved funding - drawn. With drawn at zero the
app's "Availability" was really just approved funding, so it could never match
Bibby's, which is after the 122,711.31 you have already drawn.

    172,776.09 - 122,711.31 = 50,064.78    exactly Bibby's Availability

Enter the drawn balance dated 29/08/2026, and High involvement 35,069.31 under
Save settings. Then compare line by line rather than on one number:

    Approved Debt      vs  323,029.46
    Approved Funding   vs  172,776.09
    Availability now   vs   50,064.78

Tell me WHICH line is out and by how much. If Approved Funding matches and only
Availability is out, it is just the drawn figure. If Approved Funding is out, it
is still the eligibility side and the BY CUSTOMER block in the export will show
whether anyone remains on "NO LIMIT SET".
