WHAT THIS DOES
  - Adds EXTERNAL customer / design-team logins, kept in a SEPARATE store from internal
    users so they can never inherit any internal role or area.
  - Admin > Design Customers: add a customer with name, email, company, phone, set which
    PROJECTS they can access (tick list - multiple allowed), active toggle. Creating one
    gives a temporary password to share; they're forced to set their own on first login.
  - Reset password / edit / delete per customer.
  - HARD RULE ENFORCED: external users must be scoped to specific projects. There is no
    "all projects" option, and the API rejects any attempt to save one with no projects
    or with an "all"/"*" value - now and in future.
  - External users log in on the SAME login page (email + password). On login they are
    taken straight to the Design portal and cannot reach any internal area.
