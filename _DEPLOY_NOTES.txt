WHAT'S NEW
  The Tech Sub page now works like the RFI page:
  - FULL WIDTH.
  - The old inline document preview at the top is REMOVED.
  - A table with an "Open" button. Open shows a near-fullscreen window where you can:
      * see COMMENTS at the top (light-blue panel, @mentions supported),
      * mark up the document (arrows/lines/boxes/highlight/text, colour, etc.),
      * download the document.
  - Comments: like the RFI tracker, if there are comments people are notified in ONE email
    at the END OF THE DAY. @mentions still get an immediate email.
  - Unread markers: RFIs... er, Tech Subs with new comments show the orange dot + "N new"
    on the table so you can see on login what needs reviewing (per user - clears when YOU
    open it).

  REVISIONS
  - "+ Add Tech Sub" uploads a brand-new tech sub (starts at Rev A). You can add as many
    separate tech subs as you like.
  - Each row has an "Add revision" button. Uploading a revision creates the next letter
    (Rev A -> Rev B -> Rev C ...) for THAT tech sub only. The previous revision is marked
    "Superseded" but keeps its letter; other tech subs are untouched.
  - New "Revision" column, plus a Status column (Current / Superseded). One row per
    revision (all shown).
