WHAT IT DOES
------------
"See won / lost" beside the organisation name in the deal sidebar. Opens the
SAME modal the Companies page opens when you click a company name: every project
with that customer, grouped Won / Lost / Still tendered, with values and totals,
newest first in each group.

Clicking a project in the list jumps straight to it.

REUSED, NOT REBUILT
-------------------
CompanyHistoryModal already existed as a standalone component taking company,
deals, onOpenDeal and onClose. It is called from the deal with the full deal
list, so the two entry points cannot show different answers - which a second
copy of the grouping logic would have guaranteed sooner or later.

Closes on the X or Escape only, like every other modal.

ONE THING WORTH KNOWING
------------------------
It matches on the EXACT organisation string. "Barnfield Construction Limited"
and "Barnfield Construction Ltd." are two different customers to this modal, and
your deal list has both. Same behaviour as the Companies page, so nothing has
changed - but it means a customer whose name has been typed two ways will show
split history.

Worth tidying the names at some point. I have not merged them automatically,
because Torsion Construction and Torsion Projects are genuinely different
companies and no rule can tell those apart from a typo.

A NOTE ON WHERE THE BUTTON WENT
--------------------------------
You said the Details tab. Organisation actually lives in the SUMMARY box, not
Details - the schema puts it there. The button is on the organisation row where
it is, which is what you were pointing at. Say if you would rather it moved.
