WHERE I HAVE GOT TO
--------------------
I have verified the two ends and they are both correct:

  - addActivity() does add to the deal's own activity list, with done: false
  - the Activities tab does read that list and merge it with the imported ones

So the data goes in, and the reader looks in the right place. Something between the two is
dropping it, and I have not been able to see what by reading the code. Rather than guess a
fourth time, this makes the tab show its own workings.


"WHERE ARE MY ACTIVITIES?"
--------------------------
A small expander next to the activity count. Open it and it shows:

  Added in the CRM:            how many activities exist on deals that were NOT imported,
                               and how many of those are still open
  Imported and outstanding:    the count from the Pipedrive import
  Rows built:                  how many rows the table actually assembled, and how many of
                               those came from activities added in the CRM
  On won/lost projects:        how many were set aside by the open-projects-only rule

That pins it down immediately:

  - if "Added in the CRM" is 0 right after you add one, it never reached the deal
  - if it counts yours but "of which N added in the CRM" is 0, the merge is dropping it
  - if the row is built but not visible, a filter or the open-project rule is hiding it,
    and the amber "Filtered by..." line and the won/lost line above say which

Send me those numbers after adding an activity and I can name the cause rather than
theorise about it.


TWO RULES THAT MAKE THE TWO VIEWS DIFFER LEGITIMATELY
-------------------------------------------------------
Worth ruling out first, because both are working as designed and either would look like
"it did not pull through":

  1. The tab lists OPEN activities only unless you tick "Include completed". The deal shows
     all of them.
  2. The tab lists activities on OPEN projects only. The deal shows them whatever its
     status. So an activity you set on a won or lost project will never appear on the tab.

If your test project is won or lost, that is the whole explanation - the won/lost line will
show a count. Tell me if you would rather won projects were included; you are still working
those jobs, so there is a fair case for it.
