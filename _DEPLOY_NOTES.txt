THE CHANGE
===========
In View Weekly Labour Allocations, the project name inside a cell is now clickable.
Click it, pick the project to move it to, and it is moved - the grid updates and so
does the Gantt behind it.

The picker is the same searchable one the variation tracker and builder use, so you
can type a job number or part of a name.


TWO THINGS I HAD TO BE CAREFUL WITH
=====================================
THE CELL ALREADY DID SOMETHING. Clicking a cell toggles the Overnight Allowance, and
that had to keep working. So the PROJECT NAME moves the job, and the space around it
still toggles O/A. The name is dotted-underlined to show it is clickable.

Overheads and water-ingress visits are NOT clickable - a Holiday is a category, not a
project, and a leak visit belongs to its own job list. Neither can be moved onto a
project here.

IT MOVES IN ONE SERVER CALL, not an unassign followed by an assign from the browser.
Two calls can half-succeed: if the second is refused - a clash, a dropped connection
- the person is left allocated to nothing and nobody notices until the sheet goes
out short.


AND ONE FAULT THE TESTING CAUGHT
==================================
The existing `assign` action sets the half-day outright, which is right when you are
choosing it. Reusing that for a move was destructive.

Moving somebody's MORNING onto a job they were already on in the AFTERNOON would
have replaced the afternoon entry with the morning one - quietly deleting half a
day's allocation.

Halves now merge instead:

    already am   + moving in pm    ->  full
    already am   + moving in am    ->  am    (no change)
    already full + moving in am    ->  full

A clash with a DIFFERENT project is still refused, and says so: "That person is
already on another project that day."


ALSO
-----
planning-week.js now carries projectKey on each entry. The grid was working from the
project NAME, and two jobs can share a name - a name is not a key.

The grid refreshes without the loading flash, so changing one cell does not blank
the whole table and throw you back to the top of it.
