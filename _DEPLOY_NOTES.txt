pkg484 - fixes "describeApplication is not defined" when sending
================================================================

Deploy after pkg483. One changed file: pages/api/application-send.js.

URGENT - pkg483 broke sending an application. This is the fix.


THE CAUSE
---------
I used describeApplication() to name the PDF attachment and never imported it into that
file.

The two endpoints load their imports differently, and I patched both with the same
find-and-replace without checking:

    application-pdf.js    const { ... } = await import('../../lib/applications')   dynamic
    application-send.js   import { ... } from '../../lib/applications'             static

My edit matched the dynamic line, so the PDF download picked up the import and the SEND
did not. Downloading worked; emailing threw.

The import is now on the static line where it belongs.


AND I HAVE CHECKED THE REST
----------------------------
Every file that calls describeApplication now either imports it or defines it - five
files, all verified rather than assumed. That is the check I should have run when the
function was introduced, since it was added to five places at once.
