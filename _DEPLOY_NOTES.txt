ONE REAL FINDING: lib/crmGpSnapshots.js
---------------------------------------
This file opened a connection to Redis at the top of the file, at import time,
and then NEVER USED IT. Every read and write in the file already went through
get() and set() from lib/db.js. The client was dead code.

It has been deleted rather than converted. Nothing in the file's behaviour
changes, because nothing was using it.

Worth knowing why it mattered: because it was at module scope, that connection
was built every time anything imported this file, whether or not the GP
snapshot code ran. Under multi-tenancy it would have been built before any
tenant was known.
