Customer, invoice number, project, and the amount. Built from the same rows the
column is summed from, so the detail always adds up to the figure above it.


THE DATE COLUMN IS THE USEFUL PART
----------------------------------
It says WHICH date put the invoice in that week:

  (expected)   a date you set on the Invoices owed table
  (due date)   Xero's due date, because no expected date has been set

That distinction matters when a week looks optimistic. An invoice sitting on
Xero's due date is an assumption that the customer pays on time; one on an
expected date is a judgement somebody has actually made. The column could not
show you which before.

Set an expected date in the table below and the invoice moves to the week you
really expect it - and, because that field is shared, it updates the Invoices
Owed page too.
