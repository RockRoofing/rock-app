WHAT CHANGED
------------
The Stage dropdown on Add new project starts blank, reads "Select a stage...",
is marked with an asterisk like the title, and shows a red border until one is
picked. Save is refused with "Please choose a stage."

WHY IT MATTERS MORE THAN IT DID LAST WEEK
------------------------------------------
It defaulted to Project In, so anybody who did not look at the field created the
project there without deciding to.

That was harmless when Project In was just the first column. It is not now:
pkg771 made Project In exempt from the no-activity reminders and stopped it
creating a Tender return activity. A project that lands there by accident is a
project nobody will be reminded about.

Landing in the inbox should be a decision.

THE SERVER FALLBACK IS KEPT
----------------------------
addDeal still reads `data.stageId || 'stage_project_in'`. The modal now prevents
an empty stage reaching it, but if anything else ever creates a deal without one
it goes somewhere sensible rather than into a stage that does not exist.
