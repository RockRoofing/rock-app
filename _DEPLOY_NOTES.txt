pkg454 - the timeline colour-coded by kind
==========================================

Deploy after pkg453. One changed file: pages/crm.js. No new files.


THE FOUR KINDS
--------------
    Emails       white          unchanged - the email card was already white
    Activities   blue           the same blue as "Activities to do" at the top
    Notes        yellow         the same yellow as the Notes box
    Changes      grey           the feed grey they already had

The colours are the ones each kind already uses elsewhere on the page, so nothing new has
to be learned - a yellow block is a note wherever you see it.

Rows are now cards rather than divider-separated lines: same padding, same corner radius
and same spacing as the email cards, so the four sit consistently in one column.


ONE SMALL THING WORTH THE EXTRA MINUTE
----------------------------------------
The round icon on each row is a white disc. On a plain background that was invisible; on a
tinted card it read as a hole punched through it.

It now borrows its row's border colour, so it belongs to the card. Trivial on its own, but
with four colours down the page the alternative looks like a rendering fault rather than a
design.
