pkg453 - one place to read, one place to write
==============================================

Deploy after pkg452. One changed file: pages/crm.js. No new files.


WHAT THE DEAL LOOKS LIKE NOW
----------------------------
    Activities to do        unchanged
    Notes                   the box to WRITE a note. Nothing listed underneath.
    Timeline                everything, in order, filterable

The Email section is gone. The list of saved notes under the Notes box is gone. Both were
showing the same records the timeline shows.


NOTES ARE YELLOW IN THE TIMELINE
--------------------------------
Same yellow card and border they had in the Notes section, so they still read as something
a person wrote rather than something the system recorded. Comment threads come with them -
you can still comment, edit and delete a note from the timeline.


THE EMAIL ACTIONS CAME WITH THE EMAILS
----------------------------------------
Move and Remove are on the email cards in the timeline, with the same project picker.

That mattered more than it looks: removing the section without them would have left a
misfiled email correctable only from the review queue - which it has already left by being
filed. There would have been no way to fix one at all.


ALSO REMOVED
------------
The DealEmails component itself, now that nothing renders it. A component nothing renders
is a component nobody maintains, and it would have drifted out of step with the timeline
version within a month.


ONE THING TO SANITY-CHECK AFTER DEPLOYING
-------------------------------------------
Open a project with plenty of history and confirm the Emails filter shows the same mail the
old section did. The timeline fetches it the same way, but it is a different code path and
worth ten seconds of your time.
