WHAT "0 OVERPAYMENTS" TOLD US
-----------------------------
It ruled out everything else. The deploy is live (v574 showed), the SPEND-
OVERPAYMENT type fix is in, and no error surfaced. So Xero IS returning
overpayments and my query was throwing them away.

    const where = encodeURIComponent('Status=="AUTHORISED"')

An overpayment is money that has ALREADY LEFT THE BANK, so Xero marks it PAID,
not AUTHORISED. I copied that clause from the credit-note fetch above it, where
AUTHORISED is correct precisely because a credit note is not a payment. Applied
to overpayments it excluded all of them.

Second mistake of the same shape as the first: reusing a neighbouring pattern
without checking it meant the same thing for a different object.


THE FIX
-------
No Status filter at all. RemainingCredit > 0 is the real test of "still
outstanding" - it is what is left unallocated, whatever the status says. Only
VOIDED and DELETED are dropped.


AND IF IT IS STILL ZERO, IT NOW SAYS WHY
----------------------------------------
The sync message appends the full breakdown whenever none come through:

  "117 bills, 1 credit notes, 0 overpayments. [12 returned, 0 kept, 12 not SPEND,
   0 fully allocated, 0 voided, statuses {"PAID":12}]"

That tells us in one line whether Xero returned any at all, and exactly which
test rejected them - rather than another round of me guessing. Same detail is
logged server-side.


WHAT SUCCESS LOOKS LIKE
-----------------------
"117 bills, 1 credit notes, 4 overpayments." and the total drops from
307,471.06 to 302,771.49.

Reminder - a THIRD number, by design:
  app                          302,771.49   nets overpayments off
  Xero "Bills to pay" screen   307,471.06   excludes them
  Xero raw CSV export          312,170.63   lists them positive


ALSO IN THIS PACKAGE
--------------------
Cost account filter beside the supplier filter - searchable, remembered per
browser, a bill shown if ANY of its lines is on a picked account. Credit notes
and overpayments carry lineCodes so they cannot vanish under a filter and push
the total up.
