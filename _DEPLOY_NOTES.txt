NOW THE CHANGE YOU ASKED FOR
----------------------------
Final Account now comes from the LATEST APPLICATION, falling back to Edit Project Details
when a project has no applications.

    1. manual override, if one is set
    2. latest application  - measured contract sum + variations at FINAL value
    3. Edit Project Details - contract value + instructed variations

The application is the better source: it carries variations at their final value, whereas
project details only has whatever happens to be ticked as instructed.

The Gross AFA column now says underneath which of the three it used - "application 12",
"project details", or "manual override" - so a figure that looks wrong can be traced
without opening anything.

MCD is then deducted from whichever source was used, exactly as before.
