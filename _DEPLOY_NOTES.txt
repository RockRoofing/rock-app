pkg474 - fixes the crash opening an application
===============================================

Deploy after pkg473. One changed file: pages/applications.js. No new files.

URGENT - pkg473 broke the application editor. This is the fix.


THE ERROR
---------
    ReferenceError: prevReleases is not defined
        at Array.map

The Retention section and the two release lines went into SummaryBlock - which is a
SEPARATE component from the application editor, not part of it. I read prevReleases,
locked, setApp and setDirty in there; none of them exist in that component.

The editor holds them. SummaryBlock only ever received sum and app.

It compiles cleanly because JavaScript has no idea those names will be missing until the
code runs - the same class of fault as the useMemo import in pkg430. My build check does
not catch it and neither does the prerender, because this component only renders when you
open an application.


FIXED
-----
SummaryBlock now takes what it needs:

    prevReleases      to know which half was claimed on an earlier application
    locked            to disable the tick boxes on a sent application
    onToggleRelease   a callback, so the editor still owns the state

The callback matters: the tick boxes now ASK the editor to change the application rather
than reaching for state they cannot see, which is what went wrong.


AND I HAVE ADDED A CHECK FOR IT
--------------------------------
I scope-checked every identifier in SummaryBlock against what it receives and what exists
at module level. Nothing else is missing - the only hits were words inside comments.

That check is what I should have run before shipping pkg473, given the section was added
to a component I had not looked at closely.
