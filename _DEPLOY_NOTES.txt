pkg350 - "Call" prefilled when setting the next activity
=========================================================

REPLACES pkg302 through pkg349. Deploy this one only.

CHANGED FILES
-------------
  pages/crm.js
  pages/api/crm.js        unchanged since pkg346
  lib/crmImportMap.js     unchanged since pkg305


WHAT CHANGED
------------
Mark an activity done and the "What needs doing next?" box now starts with "Call" already
in it. Leave it and you get a Call. Type over it for anything else.

Clicking into the box selects the word, so typing replaces it rather than you having to
delete it first.

If it is emptied - or left as spaces - it still saves as "Call" rather than a blank
activity. Checked all four cases: prefilled, typed over, cleared, and spaces only.


THE BUTTON IS NO LONGER DISABLED
---------------------------------
"Done & set next" used to grey out until you typed something. With "Call" already there
that made no sense, so it is always available. The quickest path is now: tick, Enter a due
date if you want to change it, press the button.

"Just mark done" is still there for when there genuinely is no follow-up.

The wording under the heading now says what it does rather than "leave blank to just mark
this one done", which no longer applies.


CONSISTENCY NOTE
----------------
This matches the deal's own add-activity box, which has always defaulted to "Call" when
nothing was typed. The two behaved differently before, which was a small trap.
