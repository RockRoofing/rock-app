THREE NEW SCORECARD CARDS (numbers pull straight from the Commercial Tasks page):

1. WEEKLY COMMERCIAL TASKS - % of the weekly tasks marked Yes, per week. Line graph of
   the % achieved each week. Target changeable (default 100% each week).

2. MONTHLY COMMERCIAL TASKS - % of the monthly tasks marked Yes, per month. Line graph
   per month. Target changeable (default 100% each month).

3. No. of WEEKLY PROJECT REPORTS - completed vs REQUIRED each week.
   - Required = every project that has at least one day marked "actual" in the Project
     Management Planning tool that week (Mon-Sun).
   - Completed = of those, how many have at least one COMPLETED project report dated in
     that week. More than one report for a project still counts once (max 100%/project -
     never 200%).
   - Shown as a % with a line graph; the card sub-line shows the latest week's
     completed/required count. Target changeable (default 100%).

NOTES
- All three only count from 30 Jul 2026 (tracking start) up to the current period -
  future periods aren't counted.
- Targets are stored as fractions (like the existing GP Margin target): to set 100%,
  enter 1; for 90%, enter 0.9. The card displays it as a %.
- "Retentions Invoiced" card was already removed in the previous scorecard package.
