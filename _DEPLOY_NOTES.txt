HOW IT WORKS
------------
BCC crm@rockroofing.co.uk and put the project's reference in the subject:

    RE: Bensham Lane drawings [CRM-972]

The reference beats every other rule, because you have said outright which project it
belongs to. Case and spacing do not matter - [crm-972], [CRM - 972] and #crm972 all work.

Verified it does NOT match ordinary prose: "Invoice CRM 2024 budget" is ignored, rather
than filing the email against deal 2024.


FINDING THE REFERENCE
---------------------
Every deal now shows its reference as a small chip in the header, next to Won/Lost/Delete:

    [CRM-972]

Click it and it copies to your clipboard, ready to paste into a subject line.


NO REFERENCE? STILL FINE
-------------------------
Anything arriving at the BCC mailbox goes through the normal matching afterwards - project
title in the subject, known contact, company domain. So a reference is the reliable way,
not the only way.

And if nothing matches, it goes to the REVIEW QUEUE rather than being discarded. That is
deliberate and different from the other mailboxes: you BCC'd it, so you have already said
it belongs in the CRM. Throwing it away for want of a reference would be wrong.


SETTING IT UP
-------------
1. Create a shared mailbox crm@rockroofing.co.uk (admin.microsoft.com -> Teams & groups ->
   Shared mailboxes). A shared mailbox is not an admin account, so the restriction that
   blocked your own mailbox does not apply.

2. Add it to the sync group:
       Add-DistributionGroupMember -Identity "CRM Sync Mailboxes" -Member crm@rockroofing.co.uk

3. In Vercel, add it to MS_MAILBOXES and drop your own address:
       crm@rockroofing.co.uk,edita@rockroofing.co.uk,Niall@rockroofing.co.uk,roman@rockroofing.co.uk

4. Redeploy, then dry run.

MS_BCC_MAILBOX defaults to crm@rockroofing.co.uk - set it if you use a different address.
