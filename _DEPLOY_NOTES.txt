ROOT CAUSE OF THE MISSING DATA
-------------------------------
Not a permissions or matching problem - I was reading the cache wrongly.

dashboard.js stores the snapshot as a BARE ARRAY:

    await redis.set('dashboard:cache', projects, { ex: 60 * 60 * 4 })

My API read it as an object:

    const rows = (snap && Array.isArray(snap.projects)) ? snap.projects : []

snap IS the array, so snap.projects was undefined, rows was always empty, and every
project fell through to "No financial data for this project yet." It would never have
worked for any project - it was not intermittent and not data-dependent.

FIXED: now accepts either shape (array, or { projects: [] }) so it cannot break again if
that store is ever reshaped.

Also improved: if the snapshot is genuinely missing (never synced), it now says so
explicitly - "Financial data has not been built yet. Open Project Financials in the portal
once, then try again" - instead of the misleading per-project message.


NEW - COSTS INCURRED TABLE
---------------------------
Under the budget cards, a table of the actual cost lines, newest first, with three tabs:

  Labour   |   Materials   |   All

Each tab shows its own total on the tab itself, then Date / Supplier + description /
Amount, with a line count and total in the footer.

CLASSIFICATION: bills lines already carry a Labour/Materials type. Wages lines predate
that field, so those fall back to the same account-code rule the bills importer uses -
your Account Categorisation config first, then the default 320/321 = labour. So the split
matches the rest of the app rather than being a second, competing rule.

LIMIT: the 400 most recent lines are sent, to keep the page usable on a phone. If a project
has more, a note says so and makes clear the TAB TOTALS ARE STILL FOR ALL LINES - only the
visible list is capped, not the arithmetic.


WORTH KNOWING
-------------
The cost lines come from costs:lines:<xeroId>, which is the same source the Budget Tracker
and EOM report use - so the totals here should reconcile with Project Financials.

The budget/spend cards still come from the 4-hourly dashboard snapshot, so both can be up
to 4 hours behind a fresh Xero sync.
