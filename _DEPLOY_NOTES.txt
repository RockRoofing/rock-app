THE OVERPAYMENT BUG (from pkg574) - MINE
----------------------------------------
Xero's Overpayment Type is "SPEND-OVERPAYMENT", not plain "SPEND". pkg573 tested
`!== 'SPEND'`, which rejected every one - so the fetch ran, succeeded, and
returned nothing, leaving the total at 307,471.06 and looking like a working sync.

fetchBankTransactions in the same file already uses `startsWith('SPEND')` at line
494 for exactly this reason. Now fixed, and it also picks up SPEND-PREPAYMENT.


WHY IT WAS INVISIBLE - ALSO FIXED
---------------------------------
sync() threw the API response away entirely inside a bare try/catch, so a failed
sync and a successful one looked identical. It now reports beside the button:

  "117 bills, 1 credit notes, 4 overpayments."   green
  "Sync failed."                                  red

The overpayment fetch also logs a breakdown server-side - how many Xero returned,
how many were kept, and how many were rejected and why.
