2. WHY SUMMARY HAD DIFFERENT TABS
---------------------------------
pages/business-financials.js had its OWN hard-coded tab list:

    const TABS = [
      ['Summary', ...], ['Budgets', ...], ['Bills to Pay', ...],
      ['Invoices Owed', ...], ['Cash Flow', ...],
    ]

Five entries, a stale copy that predates the shared nav - along with its own INK,
GOLD and gbp. So Summary showed five tabs while every other page showed thirteen,
and anything added elsewhere never appeared there.

It now renders <BizNav /> like the other twelve pages, so it cannot drift again. I
checked the rest of the section: no other page keeps a private copy.

The unused ReportImprovementLink import went with it - BizNav already renders it,
so nothing is lost.
