pkg571 - Margin page: trend value removed from the hover
=========================================================

Independent of everything else outstanding. One file.


NEW FILES
---------
  None.


CHANGED FILES (replace)
-----------------------
  pages/business-financials/margin.js


THE CHANGE
----------
Hovering a chart showed two rows - "Margin" and "Trend". It now shows the month
and its margin only. The trend line still draws; it just no longer quotes a
figure.

Applies to all four charts (FY gross, FY net, and both 12-month rolling), since
they all render through the same MarginChart component.

  hover a month with data   ->  18.4%
  hover where margin null   ->  nothing shown
  hover with no data point  ->  nothing shown


WHY A CONTENT RENDERER, NOT A FORMATTER
---------------------------------------
The obvious fix is to change the existing formatter, but recharts calls the
formatter once PER SERIES and still renders a row for each - so the trend row
would have stayed and merely been relabelled or blanked. The tooltip now uses a
custom content component that picks the margin series out of the payload and
ignores everything else.

MarginTooltip sits at module scope, not inside MarginChart - a component declared
inside another remounts on every render.

It also returns null when the margin for that month is null, so a gap in the data
no longer produces an empty tooltip box.
