WHAT CHANGES
------------
1. The Pre-Contract tile on the portal now opens the CRM.

2. The "<- Pre-Contract" back button in the CRM is gone. In its place, left-most in the
   toolbar, a two-part toggle:

       [ CRM ][ Pre-Contract ]

   Green when on, 14px bold - a size up from the Pipeline/List toggle beside it.
   Deliberately: that one switches VIEW, this one switches AREA, and they should not look
   like the same weight of decision.

3. The identical toggle sits left-most on the Pre-Contract nav, before "<- Portal", so it
   reads the same from either side. One shared component, so the two cannot drift apart.

4. "<- Deals" inside a project is untouched. That is navigation within the CRM, a
   different thing from switching area.


ONE JUDGEMENT CALL - TELL ME IF YOU DISAGREE
---------------------------------------------
I removed CRM as a TAB from the Pre-Contract nav. With the toggle sitting immediately to
its left, the same destination appeared twice, one click apart, with two different styles -
which invites the question "is the tab different from the toggle?".

The bar now reads:

    [logo] [CRM|Pre-Contract]  <- Portal | Sales Dashboard | Scorecards | Negotiating
           | Project Financials | Internal Handover Minutes | Handover Docs

If you would rather keep the tab as well, it is one line in PreContractNav.js and I will
put it back.
