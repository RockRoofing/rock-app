GOOD - THE SAVE IS FIXED
-------------------------
Activities saving inside a deal means the 413 chain is done with. What is left is purely
about what the table chooses to display.


THE MOST LIKELY CAUSE, NOW CLOSED OFF
--------------------------------------
The CRM remembers your Person responsible and Customer filters between visits. If a saved
filter is set - say a person - and you then add an activity with NOBODY assigned, that
activity cannot match it, so the table stays empty and gives no hint that a filter is even
active.

A saved filter that matches nothing at all is now IGNORED rather than obeyed, and the tab
says so:

    "A saved filter matched nothing and has been ignored.  clear it"

That single rule covers the whole class of problem: a filter set weeks ago quietly hiding
everything you add today.


IF IT IS STILL NOT THERE
-------------------------
Open "Where are my activities?" next to the activity count and send me the four numbers.
They separate the remaining possibilities in one go:

  "Added in the CRM"  is 0        -> it is not reaching the deal at all
  counted, but "rows built" low   -> the merge is dropping it
  rows built, nothing visible     -> a filter or the open-project rule
  "On won/lost projects" > 0      -> your test project is not open, and the tab only lists
                                     activities on open projects

That last one is worth checking first. If you are testing on a project marked won or lost,
it will never appear, and that is by design from pkg317 - tell me if you would rather won
projects were included, since you are still actively working those.
