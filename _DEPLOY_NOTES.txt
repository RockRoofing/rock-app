HOW TO USE IT
-------------
1. Go to  app.rockroofing.co.uk/crm-scores
2. Upload the same Pipedrive Deals export (deals-2641369-41.xlsx)
3. It shows you what it found before writing anything:

       6,860 rows, 415 carrying a score
       scored 1: 12   scored 2: 42   scored 3: 60   scored 4: 86
       scored 5: 92   scored 6: 47   scored 7: 39   scored 8: 21   scored 9: 16

4. Press the button. It reports how many were written, how many already had a score,
   and how many were not found.

No link in the nav - it is a one-off, and a permanent button labelled "import" next to a
CRM full of live data is an accident waiting to happen. Bookmark it if you need it again.


WHAT IT TOUCHES
---------------
fields.project_score. Nothing else. Not the stage, not the value, not history, not filed
email, not activities, not notes.

This is NOT a re-import, deliberately. A full import is wipe-and-replace, and the CRM now
holds plenty the export never had. Losing that to recover one dropped column would be a
bad trade.

Safe to run twice: a score already in the CRM is never overwritten, because the export is
older than the CRM, so what is in the CRM is the newer fact. Re-running only fills gaps.
If it fails partway, everything already written stays written - run it again and it picks
up the rest.


WHAT IT DOES AND DOES NOT GET YOU
---------------------------------
DOES:  the score visible on each project, under Project Score
DOES:  any Glenigan project entering Received from now on already carries its score, so
       the metric works immediately instead of waiting for somebody to type 415 numbers

DOES NOT: move the "Glenigan scored 5 or more" card for past months. That counts projects
       that entered Received in a given month, and the export has no record of when that
       happened. As agreed - forward only.

Expect a fair number of "not found". The export has all 6,860 rows including deals from
non-Project pipelines you removed, and anything deleted since. That is normal.
