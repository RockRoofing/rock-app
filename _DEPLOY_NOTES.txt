pkg291 - Report app improvement link on the Bookkeeping pages
==============================================================

CHANGED FILES
-------------
  pages/bookkeeping.js          main Bookkeeping page
  components/BookkeepingNav.js  Weekly Tasks + Monthly Tasks pages

No new files IF pkg281 is deployed - both use components/ReportImprovementLink.js, which
is a NEW file introduced in pkg281.

*** IF YOU HAVE NOT DEPLOYED pkg281, DEPLOY IT FIRST (or at least create
    components/ReportImprovementLink.js from it) or these two files will not build. ***


WHAT CHANGED
------------
The same shared "Report app improvement" link now appears on all three Bookkeeping pages:

  Bookkeeping        added directly to that page's own header (it does not use the
                     shared nav component)
  Weekly Tasks       via BookkeepingNav
  Monthly Tasks      via BookkeepingNav

Both use the shared components/ReportImprovementLink.js, so it is identical to every other
page and will follow any future change to it automatically.

The report window itself is already mounted globally in pages/_app.js, so nothing else was
needed to make it open.


PLACEMENT NOTE
--------------
On the main Bookkeeping page the top bar is already crowded (sync controls, month
selector, Upload Bills, Bookkeeping Tools) and scrolls sideways on a narrow screen. I put
the link as the FIRST right-hand item, immediately after the title, so it stays reachable
rather than being pushed off the end behind the sync buttons.

On the two task pages the bar is nearly empty, so it sits at the far right as usual.
