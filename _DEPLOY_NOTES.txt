WHAT CHANGED
------------
"What needs doing next?" now shows Call as GREY PLACEHOLDER text in an empty box, rather
than the word Call sitting there as a real value.

So it reads as a prompt - something is expected here - while leaving it alone still sets
the next activity as a Call.

  type nothing      -> activity is set as "Call"
  type something    -> that is what you get
  clear it again    -> back to "Call"

The click-to-select behaviour is gone, since there is no longer any text to select.

Wording underneath updated to match: "Leave it and the next activity is set as a Call. Use
'Just mark done' to set nothing at all."
