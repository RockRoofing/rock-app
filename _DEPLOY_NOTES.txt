pkg406 - red flag for missing information
=========================================

Deploy after pkg405. One changed file: pages/crm.js. No new files.


WHAT YOU GET
------------
A red flag on the deal card in Kanban and on the row in List view, whenever a project has
reached a stage where something should be filled in and is not.

Hover it and it names exactly what is missing:

    Missing before this can progress:

    - Credit Limit
    - Project Score
    - Lead Source

On the kanban card it sits beside the activity dot, top right. In List it shares the dot
column - adding a new column would have pushed everyone's chosen layout about.


THE RULES
---------
FROM RECEIVED ONWARDS (the yellow ones):
    Value, Organization, Contact, Project Score, Site Location, Region, Credit Score,
    Credit Limit, Project Stage, Sales Person, Project Type, Lead Source

FROM NEGOTIATING (the pink ones, on top of all the above):
    Insured Credit Limit, Roofing Works On-Site, Description of Project Scope of Works

"Received onwards" is by pipeline order, so it covers Received, Stage 1, Stage 2, Review,
MC Unsecured, Variations, MC Secured and Negotiating. Anything earlier is never flagged -
a project that has just come in is not supposed to be complete yet.

CLOSED DEALS ARE NEVER FLAGGED. Won and lost projects are history, not work outstanding,
and a board covered in flags on finished jobs would train people to ignore them.


ONE JUDGEMENT WORTH KNOWING
---------------------------
A VALUE of zero counts as missing - no job is worth nothing, so a zero there means nobody
has priced it yet.

A CREDIT LIMIT of zero does NOT. Zero is a real answer for a customer with no credit, and
flagging it would be telling you to go and fill in something already filled in.

Tested: 12 flags on an empty Received project, 3 on a Negotiating project with only the
pink ones missing, none on the same project once complete, none on anything won or lost.
