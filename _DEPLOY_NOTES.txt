DEPLOY NOTES - Markup: draggable text boxes with size / bold / underline
=======================================================================

ONE file, an EDIT - just replace it.
  components/DrawingMarkup.js

WHAT CHANGED (applies to RFI attachment markup AND the Design Drawings markup)
  The Text tool is now a proper text box you draw, not a pop-up prompt:
   - Select the Text tool and DRAG OUT a box to the size you want.
   - Type directly into the box - the writing appears on the drawing as you type.
   - A text controls row appears (when Text is selected, or a text box is selected):
       * Text size - pick from 12 up to 48
       * B - bold on/off
       * U - underline on/off
       * the colour swatches also set / change the text colour
   - Double-click an existing text box (with Select) to edit its wording again.
   - Empty text boxes are discarded automatically.
   - Existing/older text notes still display correctly.

  Everything else (arrow, line, box, circle, draw, highlight, colour, thickness, opacity,
  save markup, download) is unchanged.
