WHAT'S NEW
1. SIGNATURE block now lets the user physically SIGN with their finger (a draw-on
   canvas, works with touch and mouse) AND type their name + date. In the builder it's
   listed as "Signature (draw + name)". A "Clear" button resets the drawing. If the
   field is required, both a typed name and a drawn signature are needed. The drawn
   signature shows in the completed submission view.

2. NEW BLOCK "Site App user (allocated to project)" - in the builder choose
   "Site App user (allocated to project)". When filling the form it lists only the
   Site App users allocated to the SELECTED project (users with 'all' access or that
   project in their access list) and lets you select one or more. If no project is
   selected yet, or none are allocated, it says so.
