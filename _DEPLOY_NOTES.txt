WHAT YOU GET
A new button on the Planning page: "Accounts Weekly Labour Allocation" (next to "Send Weekly
Labour Allocation"). Clicking it opens a picker where you:
  1. Choose how many weeks (and optionally the previous week).
  2. Tick which installers to include on the report.
  3. For each installer, tick the DAYS that have an Overnight Allowance (a per-installer,
     per-day O/A grid).
Then "Download report" produces a PDF that lists only the chosen installers and marks "O/A" on
each day where you set an overnight allowance, plus a daily overnight-allowance count row.

NOTES
- Overnight selections are made in this picker each time you produce the report (they are not
  stored on the plan). If you'd like them saved/remembered between sessions, tell me and I'll
  add persistence.
- The report reads the same allocation data as the normal weekly report, so the labour shown
  matches the planner.
