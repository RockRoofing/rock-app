pkg320 - Delete companies / contacts, and a proper Mark Done column
====================================================================

REPLACES pkg302 through pkg319. Deploy this one only.

CHANGED FILES
-------------
  pages/crm.js
  pages/api/crm.js        delete actions + the deleted-names list
  lib/crmImportMap.js     unchanged since pkg305


1. MARK DONE COLUMN
--------------------
The tick box had a blank header, so it read as part of the Project column. It now has its
own header, "Mark Done", sized to fit. Nothing else moved.


2. DELETE ON COMPANIES AND CONTACTS
------------------------------------
A Delete column on the right of both tables, with a confirm before anything happens.

Deleting removes the record from that page only. Projects referencing the name are NOT
touched - no deal is changed, no history is lost, and nothing is orphaned. The confirm box
says so, because "delete company" could reasonably be read as something far more drastic.


THE PART THAT NEEDED CARE
--------------------------
pkg314 made these pages also list any company or person found on a deal, so nothing added
through a project is stranded. That feature directly fights deletion: remove a company that
appears on any project and it would simply come back on the next load, looking like the
delete had failed.

So a deleted name is now recorded in its own list and filtered out of BOTH sources - the
imported records and the deal-derived ones. Verified: a company still referenced by a live
project stays deleted.

Re-adding the same name later - through a new project, or a fresh import - lifts the
deletion automatically, so the two cannot end up disagreeing.

WORTH KNOWING: a company or contact import is still wipe-and-replace and will bring back
everything in the file, including names you deleted, because the file is treated as the
truth. Deletions made here are the right tool for tidying up after cutover, not for
filtering an import.
