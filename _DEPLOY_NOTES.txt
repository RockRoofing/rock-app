TWO CAUSES, BOTH IN THE LIST
------------------------------
VARIATIONS are only FROZEN onto an application when it is sent. Until then they are built
live from the tracker - which the editor does and the list did not. So a draft's gross in
the list excluded its variations, and both your applications showed the same 131,752.21
despite differing by £2,387.12.

RELEASES need the previous application to know which half was already claimed. The list
was not passing it.

The list now builds the application exactly as the editor does. The two agree.
