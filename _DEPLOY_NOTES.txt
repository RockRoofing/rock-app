DEPLOY NOTES - Site App: "Back to forms" returns to the previous page
=====================================================================

ONE file, an EDIT - just replace it.
  pages/forms/fill.js

WHAT WAS WRONG
  The "Back to forms" link on a form always went to the Site App home page (/forms),
  not the forms list the user came from.

FIX
  "Back to forms" now goes BACK to the previous page (router.back()) - so if you opened
  the form from the forms/browse list (with a project selected) it returns you there,
  keeping your place. Falls back to /forms if there's no history to go back to.
