WHAT CHANGED
------------
Previously the Cash Schedule used one flat "Monthly budget" per overhead, applied
identically to every month. Now the amount comes automatically from the Budgets
page's PREDICTED monthly spend, which is individual to each month (it respects each
row's forecast method, per-month overrides, and actuals for completed months).

  - Cash Schedule: the column is now "Predicted / mo" and shows the CURRENT month's
    predicted figure for each overhead. Timing settings (spread evenly / one day /
    specific days / carry) are unchanged.

  - 13-week Cash Flow: each overhead is now timed using THAT month's predicted spend,
    so a line that's forecast higher next month lands higher next month, etc. No more
    single flat figure across all months.

NOTES
