HOW IT WORKS
------------
"Download PDF" next to the month selector on Summary, and a tab in the nav.

Tick any of the 17 tabs, press Load, then Download PDF. Each tab starts on a new
page. Select all / Clear for the whole set. Paper defaults to A3 landscape so the
12-column tables fit; A4 landscape is there if you prefer.

Add ?tabs=forecast-pl,cashflow,budgets to the URL to pre-tick a set - bookmark it
for a monthly pack.

WHY IT IS NOT SERVER-SIDE
--------------------------
The obvious build is pdf-lib on the server. That would mean a SECOND implementation
of all seventeen models.

Every time this codebase has held two implementations of one rule they have drifted -
the Budgets page against the API, the P&L against the balance sheet, the cash flow
against its own fallback, the WIP window against the applications. A PDF that quietly
disagreed with the screen would be worse than no PDF, because there would be no way
to tell which one was wrong.

So the export mounts the REAL page components, fetching the REAL endpoints. What
prints is what the page computes. Change a tab and the PDF changes with it - there is
nothing to keep in step.

The trade is that it uses the browser's print engine, so it is two steps: Download
PDF opens the print dialog, and you choose "Save as PDF".

TWO THINGS TO DO IN THE PRINT DIALOG
-------------------------------------
  1. Destination: Save as PDF
  2. Turn ON "Background graphics" - without it the shading and the colour coding
     print white and the ACTUAL / MANUAL / forecast badges lose their meaning

WHAT THE PRINT STYLESHEET HANDLES
----------------------------------
  - Nav, controls and buttons removed. INPUTS ARE KEPT deliberately - they carry
    values you need to read (debtor days, retention %, manual month figures).
  - Full-height tinted page frames flattened, so you do not get a blank sheet
    before each tab.
  - Horizontal scrollers unwrapped. On screen the wide tables scroll; printed
    inside a scroller, every column past the edge silently vanishes.
  - Rows kept whole across page breaks.

NOTES
-----
  - Loading all 17 fires a lot of requests at once. Give it time, and check nothing
    still says "Loading..." before printing - it prints that way.
  - Each tab is wrapped in its own error boundary, so one page failing costs you
    that page rather than the whole export.
  - Admin only, same as the rest of the section.
