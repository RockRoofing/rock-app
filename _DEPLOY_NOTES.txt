THERE IS NO `availability` FIELD. The published position carries totalAdvance,
drawn and approvedLedger - nothing else. I assumed one when I wrote pkg689, so it
has read ZERO from the day it was written.

Which means the dashed line has only ever been CARDS + OVERDRAFT. Both are
constant. That is why it ran parallel to the cash line no matter what the
applications did - the invoice finance part was never in it.

    availability = totalAdvance - drawn = 180,000 - 122,000 = 58,000

And the rate had the same problem: totalAdvance / approvedLedger is zero if
approvedLedger is missing, so raising an application moved nothing. Falls back to
the advance rate on your IF settings now.
