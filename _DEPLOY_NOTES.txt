1. THE WORKINGS WINDOW NOW CLOSES
===================================
The x closes it, always. So does Escape. Whatever you have entered stays on the
item - every keystroke in that window is already pushed up by its auto-save, so a
part-priced item just sits on the list part-priced until you come back to it.

Save & close still asks for everything, because choosing to finish an item is a
different act from choosing to come back to it. It is no longer a dead grey button
either: press it while something is outstanding and it tells you what, rather than
sitting there disabled with no explanation, which is what made the window feel
stuck.

THE CHECK HAS NOT GONE, IT HAS MOVED TO WHERE IT BELONGS. You cannot RAISE a
variation with an unfinished item on it - that is the moment it reaches a customer,
and an item with no mark-up is priced at cost. The message names the item:

    "Additional VCL still needs a mark-up %. Open its workings to finish it."
    "3 items are unfinished: Additional VCL, Flashings, item 4. Open the workings
     on each to finish them."

Unfinished items are also flagged on the item row itself, so you can see what is
outstanding while looking at the list rather than finding out when you try to raise.

One rule, itemIssues(), used by both the window and the raise. It lived only inside
the window before, which is precisely why the window was the thing that had to
refuse - the check had nowhere else to happen.

A mark-up of 0% counts as finished. Zero is a decision; blank is not.


2. "+ RAISE NEW VARIATION"
===========================
You are right that it did nothing - on a fresh builder the blank variation is
already on screen next to it.

It is not simply deleted, because it did have one job. If you open an existing
variation from the list on the left and then want to start a new one instead,
that button was the only way back. Without it you would be stuck editing whatever
you last clicked.

So it now appears ONLY when you have a variation open, reads "Start a new variation
instead", and is a quiet outline button rather than a big black one. On a fresh
builder - your screenshot - there is no button at all.

If you would rather it went entirely, say so and I will take it out; you would then
get back to a blank variation by reloading the page.
