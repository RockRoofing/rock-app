THE ISSUE
  On first entering Schedule of Works and Deliveries, the project number showed twice -
  once in the "Project No" and again inside the project name (Xero names are stored
  like "J203 - Hollis Croft").

FIX (display only)
  A shared projectLabel() helper now shows the number once, then the name with any
  redundant leading number stripped (e.g. "J203 — Hollis Croft" instead of
  "J203 — J203 - Hollis Croft"). Names without the number are shown unchanged.

  This is purely how the label is displayed. The underlying projectNo / projectName /
  key values used for selecting a project, filtering, and every linked item are NOT
  changed - so nothing in the Site App or any linked area is affected.

  Because the shared picker is also used by the CM Site App screens (variations,
  pre-start, applications, etc.), those get the same tidy-up automatically.
