WHAT THIS ADDS (applies to Rock Drawings AND Tech Subs)
  Every approval now produces proper dispute evidence:

  1. APPEND-ONLY AUDIT LOG. Each approval is written to a separate log
     (design:approval-audit:<project>) that is only ever added to - never edited or
     deleted. So even if a drawing/tech sub is later changed or deleted, the record that it
     was approved (by whom, when, which revision, with the file fingerprint) survives.
     Internal staff can read it via /api/design-approval-audit?no=<projectNo>.

  2. FILE FINGERPRINT (SHA-256). At the moment of approval we hash the actual file bytes.
     This proves WHICH version was approved - any change to the file would give a different
     fingerprint, so nobody can later claim a different file was signed off.

  3. APPROVAL CERTIFICATE PDF. A timestamped certificate is generated automatically on
     approval and stored. It names the project, item, revision, file + fingerprint, the
     approver (name, company, role, email, phone, account ID) and the exact date/time. It's
     downloadable from the green approval panel in the viewer ("Download approval
     certificate (PDF)").

  The existing on-screen record still shows who/when; this adds the fingerprint line and
  the certificate download, plus the behind-the-scenes immutable log.

NOTES
  - Uses pdf-lib (already installed) and @vercel/blob (already used) - no new dependencies.
  - Certificates are stored in Blob under approvals/. The file fingerprint + audit entry
    are the primary evidence; the emails everyone already receives on approval remain a
    second, external record.
  - Existing approvals (approved before this deploys) won't have a certificate/fingerprint
    retroactively - only approvals made from now on.
