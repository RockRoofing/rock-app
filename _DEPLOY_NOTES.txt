pkg285 - Bookkeeping: extra monthly VAT task
=============================================

CHANGED FILES
-------------
  pages/bookkeeping-monthly-tasks.js

No new files. Straight replacement. Independent of every other package.


WHAT CHANGED
------------
One task added to the bottom of the monthly list:

  "Confirm that the month's VAT return has been filed no later than the 23rd of the month."

Placed last, directly after the existing task that asks Cotton to file the VAT - so the
request and the confirmation of it sit together and read in order.

Given the id bm14. Ids bm1 to bm13 were already used (bm13 sits mid-list, so the next free
number is 14, not the position in the list). Ids are what the tick state is stored against,
so re-using one would have made the new task inherit another task's history.

Existing ticks are unaffected - nothing else was renumbered or reordered.


ONE THING TO DECIDE
-------------------
The page subtitle still reads:

  "All monthly bookkeeping tasks to be completed no later than the 15th of each month."

This new task is due the 23rd, so that blanket statement is now wrong for one of the rows.
The same tension already exists for two others - the payroll timesheet (after the 21st)
and the payroll batch (by the 28th) - so it predates this change, but this adds a third.

Options if you want it tidied:
  - reword the subtitle to something like "...by the 15th unless a later date is stated"
  - or leave it, since each task states its own deadline in its text

Say which and it is a one-line change.
