THE CHANGE
===========
The Week column on the main table is now the same date column as the pop-out: the
date the form was completed, or the date it is needed for.

ONE DIFFERENCE FROM THE POP-OUT, and it is deliberate. The pop-out is already split
into Missing / Upcoming / Completed sections, so each can head its column "Date
needed" or "Date completed". The main table mixes all three in one list, so a single
heading cannot be honest about it.

So the column reads "Date" and each cell says underneath which kind it is:

    Mon 17 Aug 26      Sun 18 Aug 26       Tue 25 Aug 26
    needed             completed           expected

Without that, a mixed list shows two different kinds of date in one column with
nothing to tell them apart - which is worse than the week it replaced.


ALSO
-----
The table now SORTS on the date shown rather than the week, the same as the pop-out.

The day used to be tacked onto the Form column for diaries, because the date column
was only the week. It is the date column now, so that has gone - otherwise every
diary row showed the same date twice. Removed from the pop-out as well.

An obligation with no specific date still falls back to a grey "W/C 17 Aug 26".
