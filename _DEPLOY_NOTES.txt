============================================================

REPLACES pkg302 through pkg310. Deploy this one only.

-------------

WHAT IS REMEMBERED
------------------
Close the CRM, come back tomorrow, and it opens exactly as you left it:

  WHICH TAB      Pipeline / List / Companies / Contacts / Activities
  FILTERS        status (open/won/lost), estimator, any custom filters,
                 which stages are showing, and the stage mode
  COLUMNS        your chosen columns on List, Companies and Contacts - each
                 remembered separately, so a different selection per tab is fine
  SORT           the sort column and direction on every table
  ACTIVITIES     person responsible, customer, include-completed, and its sort

The one thing deliberately NOT remembered is the search box - a stale search would look
like missing data the next time you opened it, and it takes a second to retype.


HOW IT IS STORED
----------------
In the browser, not the database. These are per-person display choices that change on
almost every click; writing them server-side would mean a database write every time you
tick a column.

The trade-off: they are per browser. Log in on a different computer and you get the
defaults there until you set it up again. If you would rather they followed each user
across devices, that is a straightforward change - it just needs a per-user store and a
save on change. Say the word.

Saved preferences carry a version stamp. If the layout ever changes in a future release,
old preferences are ignored rather than restored into fields that no longer exist. A
corrupted or unreadable value is also ignored - it falls back to the defaults rather than
failing to load.


"RESET VIEW" BUTTON
-------------------
New button next to the tabs. This matters: if someone leaves a narrow filter set - say one
estimator and two stages - the CRM would open looking almost empty the next day and seem
broken. Reset View clears the lot and puts everything back to how it opens out of the box.
