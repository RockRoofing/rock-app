pkg456 - notes now record who wrote them
========================================

Deploy after pkg455. One changed file: pages/crm.js. No new files.


THE CAUSE
---------
addNote never set an author. Nothing to display, so it fell back to "Unassigned user" -
on every note, including the one you had just typed.

Comments already recorded it. Notes and activities did not, which is why one showed a name
and the other did not.


FIXED, AND NOT ONLY NOTES
-------------------------
Now recorded on:

    a note you add
    an activity you create
    an activity you complete       (from the deal or the Activities page)
    an activity you reopen

All from the logged-in portal user - the same source the comment thread already used, so
the two cannot disagree about who you are.


OLDER ENTRIES
-------------
Notes written before this have no author stored and there is no way to work out who wrote
them. The timeline HIDES the name in that case rather than inventing one, so they simply
show the date - which is what they always effectively meant.

The comment thread said "Unassigned user" for the same reason. That now reads "Unknown":
unassigned sounds like a setting somebody failed to fill in, unknown is what it actually
is. Nothing to repair - new entries carry the name from here on.
