pkg334 - Activities tab keeps itself up to date
================================================

REPLACES pkg302 through pkg333. Deploy this one only.

CHANGED FILES
-------------
  pages/crm.js
  pages/api/crm.js        lightweight activity-state endpoint
  lib/crmImportMap.js     unchanged since pkg305


WHAT IT DOES NOW
----------------
The Activities tab refreshes itself:

  - when you switch back to the CRM from another tab or window
  - every 60 seconds while you are actually looking at the Activities tab
  - whenever you press the new Refresh button

So an estimator setting or completing an activity shows up for the salesperson within a
minute, without anyone reloading. A small "updated 14:32" sits next to the button so you
can see how current it is.

Your OWN changes were always instant and still are - this is only about seeing other
people's.


WHY IT ONLY REFRESHES ACTIVITIES
---------------------------------
It re-fetches the activity list and counts, not the deals:

    full page load          ~6,400 KB
    activity refresh only     ~354 KB

Polling the whole thing would be far too heavy. This is small enough to do every minute
without anyone noticing, and it covers the case you described - progress on activities
moving between the estimator and sales.

It also stops when it should: nothing polls while you are on another tab of the CRM, or
while the browser window is in the background. Four people all sat on the tab is about
83MB an hour across the team, which is nothing.


WHAT THIS DOES NOT SOLVE
-------------------------
Two people editing THE SAME DEAL at the same time will still overwrite one another - each
browser saves its own copy of that deal, and the last save wins. With four people and
little overlap that is unlikely, and it is now limited to the specific deal being edited
rather than the whole list, because saves only send what changed.

If it does start happening, the fix is per-deal conflict detection - checking the stored
version before overwriting. Worth doing only if it actually bites.

The rest of the CRM - the board, Companies, Contacts - still shows what was loaded when you
opened the page. Say if you want the same treatment there; the deals payload work would
want doing first.
