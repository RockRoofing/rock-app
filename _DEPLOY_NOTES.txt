DEPLOY NOTES - Applications: auto-number, editable number, blank % boxes, auto-save
==================================================================================

TWO files, both EDITS - just replace them.
  pages/applications.js        (editor: number field, blank % boxes, auto-save)
  pages/api/applications.js    (assign number at create)

CHANGES
1. AUTO-NUMBERED regardless of status. Every application gets a number the moment it's
   created (App 1, App 2, ...), including drafts - not just when sent.

2. EDITABLE number. The application number in the editor header is now an editable box,
   so you can override the auto number. Your override saves and sticks (draft or sent).

3. % COMPLETE / % CLAIMED boxes (Contract Works, Variations, Materials on site):
   - The 0 is gone - an empty box is now completely blank.
   - The up/down spinner arrows are removed.
   (A blank box still calculates as 0%. Materials still default to 100% when first
   added, as before - clear the box to make it blank/0.)

4. NO MORE LOST NUMBERS ON SEND + AUTO-SAVE. The application now auto-saves as you work
   (a moment after you stop typing), so your figures and the way everything is calculated
   persist. Marking as sent / sending no longer wipes the numbers - the saved values are
   frozen as-is, and the application number carries through from draft to sent unchanged.
