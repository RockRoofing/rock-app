The button was being appended after the whole message, which put it below the sign-off and
the sender's details - so the one thing the email exists to get clicked was sitting
underneath the signature, which is where people stop reading.

Both emails: the first send and the automatic reminder.


HOW IT FINDS THE PLACE
----------------------
It splits the message at the sign-off - Kind regards, Best regards, Regards, Many thanks,
Thanks, Cheers, Yours sincerely, Yours faithfully.

The message is editable before sending, so this cannot assume the exact wording. If none
of those is found, the button falls back to the end of the email rather than disappearing.
