pkg299 - SRATs: live projects only, 25 per page, Contracts Manager column
==========================================================================

CHANGED FILES
-------------
  pages/operations/project-management/srat.js

No new files. Straight replacement. Independent of every other package.
No API change was needed - /api/srats stores the whole SRAT object, so the new field
persists on its own.


1. LIVE PROJECTS ONLY
---------------------
The project dropdowns - both the filter at the top and the picker when adding a SRAT - now
list only projects with status 'active'. Complete and Archived jobs are gone.

NOTE: this filters the PICKERS. Existing SRATs raised against a project that has since
been completed still appear in the table, which is deliberate - they are the historical
record and hiding them would lose them. Say if you would rather they were filtered out too.


2. 25 PER PAGE
--------------
Was 50. The Prev / Next control and the "Page x of y" counter already existed and adjust
automatically.


3. CONTRACTS MANAGER COLUMN
---------------------------
New column immediately after Project, as asked. It is sortable like the others - click the
header for A-Z, again for Z-A.

The column widths were rebalanced across all eight columns rather than squeezing the new
one in, so nothing gets crushed. Header, colgroup and body cells all verified at 8.

The Contracts Manager also now appears on the read-only View window.


4. AUTO-POPULATE WHEN ADDING
-----------------------------
Selecting a project on the New SRAT form fills the Contracts Manager in from that project
automatically. The field stays editable - if someone else is covering, type over it.

IT IS STORED ON THE SRAT, not looked up each time. That is deliberate: a SRAT is a record
of a moment, so it should keep showing who was responsible then, even if the project's CM
changes months later.

EXISTING SRATs have no stored CM, so for those the table falls back to the project's
CURRENT Contracts Manager rather than showing a dash. So the column is populated from day
one. From now on, each new SRAT captures its own.


TESTED
------
npm run build - Compiled successfully.
Column counts checked: 8 colgroup / 8 headers / 8 body cells.
