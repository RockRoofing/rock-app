TWO TICK BOXES IN EDIT PROJECT DETAILS
----------------------------------------
Under the MCD %:

    [x] Apply the discount to variations
    [x] Apply the discount to materials on site

Both default to ON, which is exactly how every application to date has been calculated.
Nothing changes until you untick something.

SENT CERTIFICATES CANNOT CHANGE
---------------------------------
The setting is stamped onto each application when it is CREATED, the same way mcdPct and
retentionPct already are. Change the project setting and it affects new applications only.

That mattered: the certificate is recalculated from the record every time it is opened, so
without this a sent certificate would silently re-price itself the moment somebody changed
a project setting - including the PDF, months after the customer received it.


ONE THING I COULD NOT DO CLEANLY
----------------------------------
The "Previously Cert." column is a single gross number, so it cannot be split into
measured / variations / materials on its own.

Where the previous application is in the system, its real split is used, scaled to
whatever gross is actually entered. Where it is a figure typed in by hand - a project
part-certified before it came into the app - the whole amount is treated as the MCD base.
That is the old behaviour and the more conservative of the two: it discounts more, not
less.
