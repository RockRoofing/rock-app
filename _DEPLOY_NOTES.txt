WHAT CHANGED
------------
On the Emails tab the nav search box now searches the email queue - subject,
sender name, sender address, preview text and mailbox.

The second search box in the queue header is gone. Two boxes on one screen, with
the more prominent one doing nothing, is worse than either alone.

The nav placeholder reads "Search emails..." on that tab so it is clear what it
covers. Everywhere else it is unchanged and still searches deals.

WHERE THE OLD BOX WAS
----------------------
A line showing what the search is doing:

  Search "waites" - 3 of 44        clear

Which is more useful than an empty box, because it says how much you are not
looking at.

TWO LOOSE ENDS TIDIED
----------------------
The queue's local `search` state is removed rather than left orphaned.

The "Select all" bar read that same state to decide between "Select all 12
shown" and "Select all 12". It would have kept saying "44" while the nav search
narrowed the list to three, and select-all acts on what is SHOWN - so it would
have looked like it was about to file every email in the queue. Now reads the
nav query.

The deal suggestion dropdown was already suppressed outside the deal views, so
typing here does not offer projects.
