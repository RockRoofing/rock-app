THE GAP THIS CLOSES
  A deal that's been SECURED leaves "Negotiating" but, until the handover (Internal
  Handover Minutes / pre-contract minutes) is COMPLETED, its project sits as "draft"
  and was filtered out everywhere - so secured work was invisible (not in negotiating,
  not yet live).

CHANGE
  Creating the pre-contract minutes now IS the creation of the project. DRAFT ops
  projects are now treated exactly like active ones across the system:
    - Operations planning gantt (and therefore the Commercial Cash Flow page)
    - RAMS matrix, RAMS approvals, Site badges, Forms-missing
    - Site App user project assignment
    - New-project notification now also fires when a draft is first created
  No special tag - they show like a normal project, as requested.

IMPORTANT LIMITATION (not a bug)
  The Commercial FINANCIAL views (Project Financials, WIP, Outstanding Invoices) are
  built from XERO data and keyed to a Xero tracking category. A draft project has no
  Xero financials yet, so it can't appear in those money views until it exists in
  Xero - there is genuinely nothing financial to show. It WILL appear in the planning
  programme and Cash Flow (forecast views), which is where you add it to cash flow.
