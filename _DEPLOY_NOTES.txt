HOW TO ENTER IT
---------------
Facilities -> Manual balances -> Add account:

    Name    Bibby - drawn
    Kind    Invoice finance drawn      <- new option
    Balance -122000                    <- NEGATIVE, you owe it

It counts toward CASH, not card debt - the advance has already been spent, and the
ledger it was drawn against is collected in full in the forecast. Opening cash
becomes 2,500 less 122,000 = -119,500 on both the 13-week and the 12-month.

Warns if you type a positive, the same way the card rows do.


NO DOUBLE COUNT
---------------
The repayment rule from pkg717 SWITCHES ITSELF OFF the moment an if-kind account
exists. So whichever way you enter it, the 122k comes off exactly once - and if
you later delete the account, the rule takes over again rather than the money
quietly reappearing.
