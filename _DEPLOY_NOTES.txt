1. WHY THE SAVE KEPT FAILING WITH 413
--------------------------------------
The autosave was sending the ENTIRE deals list on every change.

    crm:deals for 6,860 projects   ~6.4 MB
    Vercel request body limit       4.5 MB   (hard, before your code runs)

It could never have worked at this size. It only survived until now because the CRM held a
few hundred sample deals - the real import is what pushed it over. Raising the Next.js body
limit does not help; the 4.5MB ceiling is Vercel's and sits in front of everything.

pkg323 trimmed the payload by stripping imported records, which helped but was not enough.
This is the actual fix.

NOW: each save compares every deal against the version last successfully saved and sends
ONLY the ones that differ. Editing one project sends one project - a few kilobytes instead
of 6.4MB. The server merges those into the stored list by id.

Two details that make it reliable:

  - the baseline only advances when a save SUCCEEDS, so a failed save is retried in full
    on the next change rather than being quietly forgotten
  - the in-memory kanban summaries are excluded from the comparison, otherwise every deal
    would look changed and we would be back to sending everything

Deleted projects are handled too - removals are sent as a list of ids.


2. MARK DONE / PROJECT COLUMNS SWAPPED
---------------------------------------
Exactly as your screenshot showed. When I added the tick box in pkg319 I put the CELL after
the project name but the HEADER before it, so the two headings read across the wrong
columns. The tick box is now the first cell, matching its header. Nothing else moved.


WHAT TO EXPECT
--------------
Add an activity inside a deal. The badge should go "Saving..." then "Saved" in green - not
red. Reload, and it should still be there and in the Activities tab.

If the badge does go red again, the message will carry the status code. But 413 should now
be impossible: a single changed deal is a fraction of the limit.

-------------

Worth spot-checking a couple of projects you know you edited.
