WHAT THIS IS (first slice of the Project Cash Flow feature)
  A new Commercial > Cash Flow tab that MIRRORS the Operations planning programme:
    - Same projects (live + negotiated), same dates/sequence, day & week views,
      Historic toggle, Today / back / forward nav - all reading the live planning
      data, so if Operations move a project this moves with it.
    - Gantt bars are GREYED and BLANK (no numbers) - just showing when work is
      planned, per your spec.
    - "Planned / Actual" and "Contract Compl." columns shown (read-only mirror).

  PERIOD SELECTION: click/drag across the cells on ANY project row - with or without
  bars - to select a period. A bar at the top shows the project + date range with a
  "Build application ->" button. That button is a placeholder for now (it just
  confirms the period); the hypothetical application document is the NEXT phase.

  Nothing here writes to the programme or to applications - it's read-only + local
  selection only.
