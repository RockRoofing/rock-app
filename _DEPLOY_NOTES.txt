pkg292 - Contracted Rates: labour and materials budget on every line
=====================================================================

CHANGED FILES
-------------
  pages/forms/cm/contracted-rates.js      Site App, Contracts Manager view

No new files. Straight replacement. Independent of the other packages.


WHY ONLY THIS FILE
-------------------
The PORTAL Contracted Rates page (pages/contracted-rates.js) already shows all four
columns per line - Mat rate, Mat total, Lab rate, Lab total - so nothing was needed there.

The gap was the SITE APP Contracts Manager view. It only ever rendered qty, unit, rate and
the line total, even though the API was already sending the full item records with matRate
and labRate on them. The figures were in the payload and simply were not being drawn.

If you meant the portal page instead, say so - but there was nothing missing on it.


WHAT YOU NOW SEE, PER LINE
---------------------------
Under each rate line, two small panels:

  Materials   the budget for that line, with the rate underneath (@ £6.20)
  Labour      the budget for that line, with the rate underneath (@ £5.10)

Budget = qty x rate, calculated with lineMatTotal / lineLabTotal imported from
lib/contractRatesParser - the SAME helpers the portal page uses. So the numbers cannot
drift apart from the portal, and a change to that calculation updates both at once.

Lines with no materials or labour rate (TBC / rate-only items) show nothing extra rather
than a row of dashes.


ALSO ADDED
----------
The green "Contract works total" bar now carries the section totals too:

  Materials budget £x,xxx.xx     Labour budget £x,xxx.xx

Taken from cr.totals.aboveMaterials / aboveLabour, which the API was already computing and
sending - again, the same figures the portal shows.

Above-the-line only, matching what this screen already displayed. Below-the-line
(optional / variation) items remain hidden here as before.


TESTED
------
npm run build - Compiled successfully.
Per-line and section arithmetic checked against the shared helpers.
