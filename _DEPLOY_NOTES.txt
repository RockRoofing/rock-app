pkg501 - the Customer filter, actually on the Strike Rate page this time
========================================================================

Deploy after pkg500. One changed file: pages/sales-crm.js. No new files.


WHY pkg478's FILTER NEVER APPEARED
------------------------------------
I added it to the shared filter bar. The Strike Rate page does not render that bar at all -
it has its own filter block, which is why the date range and the score buttons on it look
different from the other pages.

So the control existed, was correctly gated to the Strike Rate page, and was attached to
something that page never draws. It could not have shown up.

I should have checked where that page's filters come from rather than assuming every page
used the shared one.


NOW IT IS ON THE PAGE ITSELF
------------------------------
    Customer  [All customers            v]   clear

Directly above the existing filter block. Pick a contractor and the whole page - rate,
values, chart, detail - is that customer only.

Listing every organisation with a decided deal above £0, since strike rate is only
meaningful on work that has been won or lost.

The version in the shared bar has been removed, so there is only one of them.


CUSTOMER TYPE REMOVED
---------------------
Gone from the shared filter bar, and no longer applied to the data.

That second part matters: the filters are remembered between visits, so leaving the
filtering in place with the control gone would have meant anybody with "Main Contractor"
saved kept seeing a narrowed set with nothing on screen to explain it.

The field itself is untouched on the deals - only the filter has gone, so it can come back
if you want it. Projects Priced has its own separate filter set and is unaffected.
