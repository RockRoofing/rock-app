-------------------------------------------
  pages/crm.js

NEW FILES
---------
  NONE.


WHAT CHANGED
------------
Inside a project, the title in the black header is now a copy button. Click it and the
project title goes to your clipboard. A small grey "copy" hint sits next to it so it is
obvious it does something, and it says "Copied" for a second and a half afterwards.

The [CRM-nnn] chip next to Won/Lost now uses the same button, so both behave identically.
Previously it copied silently - you clicked and nothing happened on screen, so there was
no way to tell whether it had worked.

If the copy fails it says "Copy failed" rather than pretending. There is a fallback for
browsers where the clipboard API is unavailable, which covers older phones and anything
not on https.


WHY A SHARED COMPONENT
----------------------
Both copy buttons now run through one CopyButton component rather than each having its own
handler. Anywhere else you want a copy button, it is one line and it will look and behave
the same as these two.
