WHAT THIS IS
  The old "Contract Drawings" tab is renamed to "Handover Docs". (Note: the old drawings
  upload there never actually stored files - this replaces it with something that works.)
  The old contract-drawings page/route is left in place but is no longer linked in the nav;
  it can be deleted later.

  Handover Docs:
  - FULL WIDTH.
  - "+ Add Section" - name a section (e.g. "O&M Manuals", "As-Builts").
  - Within each section, "+ Upload documents" (any file type; multiple at once).
  - Documents show as THUMBNAILS (image preview, or PDF first-page preview) - not a table.
    Click a thumbnail to view; each has its own Download.
  - DOWNLOADS as a single ZIP:
      * "Download all" (top right) - everything across all sections.
      * Tick the checkboxes on thumbnails, then "Download selected".
      * Per section: "Select all" and "Download section".

NOTES
  - Customers can view and download; adding sections / uploading / deleting is Rock Roofing
    (internal) only.
  - Uses the existing Blob upload + the download proxy. The zip is built on the server and
    streamed back, so very large sets take a few seconds.
