ACTIVELY CHASED SCORED >=5
--------------------------
Identical rule to the Glenigan one: reached Received in that month, and scores 5 or more
as it stands today. Lead source is read as it is NOW, so a project marked Actively Chased
after it was received still counts, dated by when it was received.

"Actively Chased" is matched on the lead source you added in pkg380. Nothing will show
until projects start carrying it - and, like the Glenigan card, it needs a received date,
which only exists for stage moves the CRM has watched. Forward-only, as agreed.


AVERAGE VALUE OF PROJECTS PRICED
--------------------------------
Same rolling shape as the secured one - 6 months to the month shown, with the previous
6 underneath and the direction of travel.

One decision worth knowing: it averages per PROJECT, not per pricing event. A project
repriced three times in the window is still one project. Averaging the events instead
would let a single job that got revised a lot drag the whole figure about.

Each project is taken at the LAST price set in the window - the current answer, not the
first guess.


TARGETS
-------
Defaults for the two new cards are placeholders and almost certainly wrong:

    Actively Chased scored >=5        3 / month
    Average value of projects priced  £200,000

Set the real ones with the pencil on each card. The targets for the five removed metrics
are left in the defaults file - harmless, and they belong to cards that may come back.


LEFT IN PLACE ON PURPOSE
------------------------
The calculations behind the removed cards still run. They feed drill-downs elsewhere and
cost nothing, and tearing out working code to remove three cards from a list is a risk
with no upside. If you want them properly gone, say so and I will do it as its own change
where it can be checked on its own.
