pkg532 - Add variation from Contracted Rates
============================================

Deploy after pkg531.

CHANGED FILES (replace)
-----------------------
  pages/contracted-rates.js
  pages/api/contracted-rates.js

NEW FILES: none.


FOUR FAULTS IN ONE FLOW - three of them mine from pkg524
----------------------------------------------------------

1. THE IMPORT NEVER LANDED, so Add variation threw.

   pkg524 appended the import to this line:
       import { useState, useEffect, useMemo, useRef } from 'react'
   but contracted-rates.js has no useRef. The replace matched nothing and failed silently,
   so SendVariationModal and BASE_CLARIFICATIONS were used and never imported.

   That is the third time a find-and-replace has half-applied and shipped. I check the
   result now rather than the return code.

2. THE API DROPPED THE BUILDER BLOCK. to-variation rebuilt the variation field by field
   and did not carry it, so a variation raised from the rate schedule had no items, no
   clarifications and nobody recorded as raising it - nothing to send, nothing to
   instruct, nothing for View to show.

3. INSTRUCTED WAS STORED AS A BOOLEAN. The endpoint wrote !!v.instructed while everything
   downstream tests instructed === 'yes'. true === 'yes' is false, so a CR variation could
   never have read as instructed - it would have sat outside the final account for ever.

4. THE PAGE STRIPPED THE CUSTOMER CONTACTS. It maps each project down to seven fields, and
   customerContacts and orderRef were not among them - so the send window would have
   opened with no recipients and no sub-contract ref.


WHAT YOU GET NOW
----------------
Select lines on the Contracted Rates, press Add variation, and it:

    creates the variation with its items priced at the contracted rates
    numbers it from the tracker
    carries the standard clarifications, the sub-contract ref and who raised it
    OPENS THE SAME SEND WINDOW as the Variation Builder

Same email, same instruct button, same instruction coming back. A variation raised here is
indistinguishable from one built by hand.
