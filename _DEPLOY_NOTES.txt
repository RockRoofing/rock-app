pkg440 - N/A on the retention releases when retention is 0%
===========================================================

Deploy after pkg439. One changed file: pages/retention.js. No new files.


WHAT CHANGED
------------
On a project with 0% retention, all four release columns now read a greyed "N/A":

    1st Value    1st Date    2nd Value    2nd Date

They were showing an amber "TBC" warning, for ever, on projects that were never going to
have a release date - chasing something that does not exist. Hovering any of them says
"Retention is 0% on this project - nothing to release."

I did all four rather than only the two dates you mentioned. A £0.00 release value beside
an N/A date would have read as a release that had not been valued yet, which is the same
confusion in a different column.


ONE DISTINCTION THAT MATTERS
----------------------------
Only an EXPLICIT zero counts. A BLANK retention still shows the TBC warning.

Blank means nobody has set the retention yet - that is a project needing attention, and
exactly the thing this register should be surfacing. Treating blank as zero would have
quietly hidden them.

Checked: 3% behaves normally, 0 and "0" show N/A, blank and null keep the warning.


ALREADY CORRECT, LEFT ALONE
---------------------------
The Retention Owed / 612 Allocated match flag only fires when one of the two is above
zero, so a 0% project does not show a false mismatch there. Nothing needed.
