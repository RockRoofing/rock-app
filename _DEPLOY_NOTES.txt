THE CHANGE
===========
"Select staff..." in the Overheads day modal is now typeable. Type any part of a
name and the list narrows; arrows move, Enter picks, Escape closes.

Same component the variation tracker, the variation builder and the WLA project-move
already use. A native select does have type-ahead, but it only matches the START of
the option, so typing a surname on a roster this long found nothing.


NOT CHANGED, DELIBERATELY
--------------------------
The only other operative dropdown in the planner is the installer filter on "Review
past O/A". That lists only people who actually have an overnight allowance recorded,
which is a short list - and a search box on six options is friction rather than help.
Same reasoning as leaving Customer, CM and Estimator as plain selects on the
variation tracker.
